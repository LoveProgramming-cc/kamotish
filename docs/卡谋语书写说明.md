# 卡谋语（Kamotish）书写说明

> 本文档写给 AI 阅读。读完之后，你应当能用下面规定的**输入格式**写出卡谋语文本，由渲染组件
> （`web/kamotish.js`）立刻显示成卡谋语文字。你只需要输出符合本文格式的**纯文本**，
> 不需要也不可以输出图片、SVG 或别的符号。

---

## 0. 先记住这五条

1. 卡谋语文字有三类内容：**字素**（`\名字`）、**拼读**（直接写拉丁字母）、**汉字等其他字符**（原样）。
2. 拼读按**音节**写。一个音节最多有 4 个位置：**A 辅音 + B 元音 + C 元音 + D 辅音**，A、C、D 可以缺。
3. 音节之间用 `-` 隔开（`-` 不显示）；要显示真正的横线，写两个 `--`；空格会显示为词间空隙。
4. 辅音右上角的小圆圈用字母组合表示（`sh ch zh ng st`，以及 `ts ps ks` 这类“辅音+s”），**不要自己画圈**。
5. 音调是可选的，写在音节或字素后面：`\1` `\2` `\3` `\4`。默认不写音调。

---

## 1. 输入格式总览

整份文本由若干**段落**组成，段落之间空一行。段落内换行会显示为换行。以 `# ` 开头的段落是标题。

段落里的每个字符按下面的规则分类：

| 你写的 | 含义 | 例子 |
|---|---|---|
| `\` + 名字（+ `\` + 数字） | 一个**单独字素**，可带音调 | `\mou` `\mou2` `\mou\1` |
| 连续的拉丁字母（+ `\` + 数字） | 一个**音节**，可带音调 | `ma` `jian` `shao` `liang\3` |
| `-` | 音节分隔符，**不显示** | `ma-tas-jian` |
| `--` | 显示一个真正的横线 `-` | `ma--tas` |
| 空格 | 显示为一段空隙（词与词之间） | `ma-tas su-kun` |
| 其他一切（汉字、标点、数字…） | **原样显示** | `我叫`、`，`、`2026` |

**重要约定**

- 拉丁字母一律当作拼读，所以**不要在文本里夹英文单词或别的拉丁文字**（它们会被当成音节，
  读不出来时显示为红色原文）。
- 拼读请用**小写**字母（大写也能识别，但统一写小写）。
- 音节之间既可以用 `-` 连接，也可以直接用空格隔开。一个“词”里的各音节用 `-` 连接，词与词之间用空格。
- 一个音节的字母必须**连在一起**，中间不能有 `-` 或空格。

---

## 2. 拼读：音节怎么写

### 2.1 一个音节由四个位置组成

```
      ┌────────┬───┐
      │   A    │ B │     A = 辅音（左上，较大）
      │ 辅音   │元音│     B = 元音，竖着写（A 的右边）
      ├────────┴───┤     C = 元音，横着写（A 的下面，横贯整块）
      │  C  横元音  │     D = 辅音（最下面，写得比 A 更扁）
      ├────────────┤
      │   D 辅音   │
      └────────────┘
```

整块写成**一个汉字那么大**。同一个辅音在 A 位置和 D 位置的写法**不一样**（A 形、D 形），
这由渲染组件自动处理，你只需要写字母。

### 2.2 字母表

**辅音（21 个）**：`b c d f g h j k l m n p q r s t v w x y z`

**元音（5 个）**：`a e i o u`

> `y`、`w` 是辅音；元音只有 `a e i o u`。

### 2.3 把一个音节拆成 A B C D

音节字母的顺序是 **[A][B][C][D]**，即 **[声母][元音一个或两个][韵尾]**：

1. 从头开始，第一个元音之前的字母是 **A（声母）**，可以没有。
2. 接着连续的元音：**1 个元音 → 只占 B**；**2 个元音 → 依次占 B、C**。不能超过 2 个。
3. 元音之后剩下的字母是 **D（韵尾）**，可以没有。

| 音节 | A | B | C | D | 说明 |
|---|---|---|---|---|---|
| `ma` | m | a | — | — | 一个元音，只有 B |
| `tas` | t | a | — | s | |
| `kun` | k | u | — | n | |
| `jian` | j | i | a | n | 两个元音 B、C 都有 |
| `houl` | h | o | u | l | A、B、C、D 俱全 |
| `neen` | n | e | e | n | |
| `an` | — | a | — | n | 没有声母 |
| `a` | — | a | — | — | 只有一个元音 |

### 2.4 小圆圈（°）：用字母组合表示

辅音的右上角可以带一个小圆圈，用来表示“加 s”“h 化”“ng”“st”。**你不要画它，只要写出对应的字母组合**，
组件会自动识别并在正确的位置画圈。

| 位置 | 你写的 | 组件画成 | 例子 |
|---|---|---|---|
| A（声母） | `sh` | **s** 加圈 | `shao` |
| A | `ch` | **c** 加圈 | `chang` |
| A | `zh` | **z** 加圈 | `zhi` |
| A | 辅音 + `s`（不含 s、c、z） | 该辅音加圈（读作“辅音 + s”） | `tsao`（t 加圈）、`psa` |
| D（韵尾） | `ng` | **n** 加圈 | `liang`、`xing` |
| D | `st` | **s** 加圈 | `moist` |
| D | 辅音 + `s` | 该辅音加圈（读作“辅音 + s”） | `oits`（t 加圈）、`bats` |
| D | 单个辅音 | 不加圈 | `tas`（s 就是普通的 s） |

注意：

- 只有上表列出的组合才会画圈，其他多辅音组合**不能表示**（见 2.7）。
- A 位置的 `s`、`c`、`z` 单独出现就是普通的 s、c、z；写成 `sh`、`ch`、`zh` 才带圈。
- 字尾的 `s` 单独出现就是普通 s（`tas`）；写成 `ts`、`ks` 等才是“辅音加圈”。

### 2.5 缺少某个位置时怎么显示

组件按下面的规则自动处理，**你只管写字母**：

| 缺什么 | 显示方式 |
|---|---|
| **缺 A**（如 `an`、`oits`、`a`） | 用字素 **ii**（两笔短画）放在 A 的位置，保持它自己的形状 |
| **缺 C**（只有一个元音，如 `kun`、`tas`） | 不写 C，版式不变，整体重新居中 |
| **缺 D**（没有韵尾，如 `jia`、`kua`） | 不写 D，把剩下的内容**竖直拉到整个字高**（拉到 C 的下沿），所以不会比别的字矮 |
| **缺 C 和 D**（如 `ma`、`su`、`shi`） | 只有 A 和 B，同样**竖直拉到整个字高**，居中 |
| **只有 B**（如 `a`、`e`） | A 位置是 ii，再加 B，拉到整个字高，居中 |

### 2.6 元音在 B、C 位置的样子（仅供理解，组件自动画）

| 元音 | B 位置（竖） | C 位置（横） |
|---|---|---|
| `i` | 一条竖线 | 一条横线 |
| `a` | 两条竖线 | 两条横线 |
| `o` | 工字（竖线 + 上下两小横） | 横过来的工字 |
| `u` | 两条竖线中间一小横（像 H） | 两条横线中间一小竖 |
| `e` | ⊤ 或 ⊥ | ⊢ 或 ⊣ |

`e` 有两种写法，是为了避免和 A、D 的笔画挤在一起，**组件自动选**，你不用管。

### 2.7 组件不支持的写法（会显示为红色原文）

写这些会无法渲染，请避免：

- 声母有两个以上辅音（`str-`、`tr-`、`bl-`…），除上面列出的 `sh ch zh` 和“辅音+s”。
- 三个及以上连续元音（`uai`、`iao`…）。
- 没有元音的音节（`m`、`ng`、`sh` 单独出现）。
- 韵尾是别的辅音组合（`-sh`、`-ch`、`-nt`、`-ld`…），只支持 `ng`、`st` 和“辅音+s”。
- 字母以外的字符混在音节中间（如 `ma1`，音调要写成 `ma\1`）。

遇到外来词或汉语词，需要把它**近似成上述格式的音节**。例如英文 *sentimentalization*：
先按音节切分成 `sen ti men tal li za tion`，再按卡谋语的音系近似成 `san-ti-man-tol-lai-zei-shion`。
（`tion` 近似为 `shion`；`shion` = sh + i + o + n，其中 sh 的 s 加圈，i、o 占 B、C，n 是 D。）

## 3. 单独字素：`\名字`

有些字符在句子里**单独**出现，不属于某个音节块。这类字素用反斜杠 `\` 加名字写：

```
\mou          一个字素
\mou2         同一个读音的第二个字符（名字后面加 2）
\mou\1        带音调 1 的字素
\mou2\3       第二个字符，带音调 3
```

### 3.1 全部字素名

下面是所有可用的名字（**必须完全一致**，全是小写）：

```
a   bi   bou   chi   e   ga   ha   hou   hou2   i   ii   ka   kou   ku   le   lou
mi  mou  mou2  nou    ou  pou  ri   sei   shi    sou te  tou  wou   wu   xi   yu   zhi
```

其中有三组**同形不同音**，画的是同一个字形：

| 名字 | 同形的另一个名字 |
|---|---|
| `hou2` | `mi` |
| `mou2` | `ri` |
| `le` | `sou` |

名字里的数字 `2` 表示“这个读音的第二个字符”（如 `hou`/`hou2`、`mou`/`mou2`）。注意 `\mou2` 是**字素名**，
而 `\mou\2` 是“字素 `mou` 带音调 2”，两者不同。

### 3.2 字素和辅音、元音字母的对应

单独字素的名字与前面拼读用的字母有如下对应关系（用于理解，**写文本时直接用字母拼读，不需要写字素名**）：

| 辅音字母 | 字素名 | 辅音字母 | 字素名 | 辅音字母 | 字素名 |
|---|---|---|---|---|---|
| b | `bi` | j | `xi` | s | `le`（= `sou`） |
| c | `e` | k | `kou` | t | `tou` |
| d | `wu` | l | `ha` | v | `pou` |
| f | `ka` | m | `mou` | w | `wou` |
| g | `ga` | n | `lou` | x | `zhi` |
| h | `hou2`（= `mi`） | p | `ku` | y | `chi` |
| q | `hou` | r | `mou2`（= `ri`） | z | `shi` |

元音字母的单独字素：`a`→`\a`，`i`→`\i`，`o`→`\ou`，`u`→`\bou`，`e`→`\yu`。
另有几个不对应单个字母的字素：`ii`、`nou`、`sei`、`te`。

> 在拼读里**不需要**写这些名字：写 `jian`，组件会用 j、i、a、n 各自的 A 形、D 形和元音写法自动拼出整块。
> `\名字` 只在你需要**单独放一个字素**（比如举例、列表、标注）时使用。

### 3.3 音调

音调写在字素或音节**后面**：`\1` `\2` `\3` `\4`。

- 字素：`\mou\1`
- 音节：`ma\1`、`tas\2-jian`（音调只属于它前面紧挨着的那个音节）

音调符号画在字素或整块的**右上角**。形状分别是：1 一撇，2 两撇，3 V 形，4 碗形加一点。
**默认没有音调**，除非需要标明，否则不要写。

---

## 4. 空格、连字符和标点

- `-`：音节分隔符，不显示。`ma-tas-jian` 与 `ma tas jian` 的区别：前者各音节紧挨着，后者音节之间有较大空隙。
  习惯上**一个词里的音节用 `-`，词与词之间用空格**。
- `--`：显示一个真正的横线。例：`ma--tas` 显示为 ma 块、一条横线、tas 块。
- 空格：每个空格显示一段固定空隙；连续写几个空格就有几段空隙。
- 标点和汉字：原样显示，不受上面规则影响。例：`我叫 ma-tas-jian，他叫 su-kun-liang。`

## 5. 完整示例

**输入**

```
# ka-mo-yu

我叫 ma-tas-jian，他叫 su-kun-liang。

\mou\1 是单独的字素，\wou\2 和 \hou2 也是。

shao xing moist oits tsao ma--tas an a in e
```

**说明**

- 第一行是标题（以 `# ` 开头）：`ka`、`mo`、`yu` 三个音节块，音节之间用 `-` 连接。
- 第二段：汉字原样显示；`ma-tas-jian`、`su-kun-liang` 各是一个词，里面的音节块紧挨着。
- 第三段：`\mou\1` 是字素 `mou` 带音调 1；`\wou\2` 是字素 `wou` 带音调 2；`\hou2` 是第二个 `hou` 字素。
- 第四段：演示小圆圈和缺失规则：
  - `shao`：A 是 s 加圈（sh）；`xing`：D 是 n 加圈（ng）；`moist`：D 是 s 加圈（st）；
  - `oits`：缺 A，D 是 t 加圈（ts）；`tsao`：A 是 t 加圈；
  - `ma--tas`：中间显示一条横线；
  - `an`、`a`、`in`、`e`：缺 A，用 ii 代替。

## 6. 写作检查清单（输出前逐条核对）

- [ ] 拉丁字母全部小写，且全都属于 `b c d f g h j k l m n p q r s t v w x y z a e i o u`。
- [ ] 每个音节：**至多一个声母**（或 `sh ch zh` / 辅音+s），**1 到 2 个元音**，**至多一个韵尾**（或 `ng` / `st` / 辅音+s）。
- [ ] 每个音节至少含 1 个元音。
- [ ] 音节内部没有 `-`、空格、数字。
- [ ] 音调写成 `\数字`，紧跟在音节或字素之后，数字只能是 1 到 4。
- [ ] 字素名拼写与第 3.1 节的列表完全一致。
- [ ] 需要显示横线时用 `--`；只想分隔音节用 `-`。
- [ ] 没有夹杂英文单词或其他拉丁文本。
- [ ] 标题行以 `# ` 开头，段落之间空一行。

### 常见错误

| 错误写法 | 问题 | 正确写法 |
|---|---|---|
| `ma1` | 音调不能直接写数字 | `ma\1` |
| `tra` | 声母 `tr` 不支持 | 近似为 `ta` 或 `tara`（分成两个音节：`ta-ra`） |
| `uai` | 三个元音 | 拆成两个音节，如 `u-ai` |
| `cash` | 韵尾 `sh` 不支持 | 近似为 `ka-shi` |
| `Ma-Tas` | 大写 | `ma-tas` |
| `ma - tas` | 空格破坏音节 | `ma-tas` |
| `\Mou` | 字素名必须小写 | `\mou` |
| `\mou 1` | 音调必须紧跟反斜杠 | `\mou\1` |

## 7. 使用渲染组件

组件是一个独立的 JavaScript 文件，**不依赖任何库，不需要服务器**。

### 7.1 在网页里使用

```html
<script src="kamotish.js"></script>

<kamo-text>
我叫 ma-tas-jian，他叫 su-kun-liang。
</kamo-text>
```

- 标签里的文字就是输入；也可以写成属性：`<kamo-text text="ma-tas-jian"></kamo-text>`。
- 组件的文字大小由外面的 CSS 决定：给 `kamo-text` 设 `font-size`，字素和音节块都按这个大小显示，
  与汉字等大。
- 想让内容实时变化，改它的 `text` 属性或 `textContent` 即可（它会立刻重画）：
  ```js
  document.querySelector('kamo-text').text = 'ni-hao ma\\1-tas';
  ```

### 7.2 用脚本调用

```js
Kamotish.render('ma-tas-jian');          // 返回一段 HTML 字符串（每个字素/音节是一个内联 <svg>）
Kamotish.mount(element, 'ma-tas-jian');  // 把渲染结果放进某个元素
Kamotish.parseSyllable('shao');          // 查看一个音节被怎么拆分（读不出来时抛出错误）
```

### 7.3 样式说明

- 颜色跟随文字颜色（`currentColor`），所以深色模式、改字色都自动生效。
- 每个字素/音节块是 1em × 1em 的内联图形，垂直方向与汉字对齐。
- 读不出来的音节会显示成**红色原文**，鼠标放上去有错误提示。

演示页：`web/demo.html`（可以直接在浏览器里打开，边输入边显示）。

---

## 8. 一句话总结（给 AI 的操作指令）

> 用拉丁字母**按音节**写卡谋语：每个音节 = [声母][1–2 个元音][韵尾]，音节之间用 `-`，词与词之间用空格，
> 汉字和标点原样保留；需要单独放字素时写 `\字素名`；需要音调时在后面加 `\1`–`\4`；
> 不要使用本文没有列出的写法。

## 9. 嵌入普通文字：`\kamotish{ … }`

如果你的输出会放进**普通网页文字、聊天、文档**里（不是整段都是卡谋语），把卡谋语的部分包在
`\kamotish{` 和 `}` 之间，浏览器插件会把括号里的内容渲染出来，括号外的文字不受影响：

```
我叫 \kamotish{ma-tas-jian}，他叫 \kamotish{su-kun-liang}。
```

括号里面的写法**就是本文前面所有规则**（拼读、`\字素名`、音调、`-`、`--`、空格）。唯一多出来的规则是转义：

| 想在括号里得到 | 写成 |
|---|---|
| `{` | `\{` |
| `}` | `\}` |
| `\` | `\\` |

其余的反斜杠原样处理，所以字素和音调直接写：`\kamotish{\mou\1}`。括号不能嵌套，括号里没有 `}` 结尾则不处理。
括号里可以含加粗、链接等格式（会被去掉）；括号外的文字原样保留。

> 含大写字母的单词（如 `AI`、`Kamotish`）不会被当作卡谋语读音，原样保留为普通文字；卡谋语读音一律用小写。
