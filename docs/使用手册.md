## 一、卡谋语怎么输入

完整规范见 [卡谋语书写说明](卡谋语书写说明.md)。这里是简要版。

### 1. 三类内容

| 写法 | 含义 | 例子 |
|---|---|---|
| `\名字` | 一个**字素** | `\mou` `\wou` `\hou2` |
| 连续的小写拉丁字母 | 一个**音节** (拼读) | `ma` `jian` `shao` |
| 汉字、标点、数字等 | 原样显示 | `中国人` `,` `1969` |

### 2. 字素

全部字素名 (必须完全一致，全部小写)：

```
a   bi   bou  chi  e    ga   ha   hou  hou2 i    ii   ka   kou  ku   le   lou
mi  mou  mou2 nou   ou   pou  ri   sei  shi  sou  te   tou  wou  wu   xi   yu   zhi
```

有三个字各有两个读音，按句中的读音输入，显示出来是同一个字：`mi` 和 `hou2`、`sou` 和 `le`、`ri` 和 `mou2`。
注意 `hou2`、`mou2` 里的 `2` 是名字的一部分，不是声调：“他”写 `\hou2\i`，不是 `\hou\i`。

### 3. 音调

写在字素或音节后面：`\2` `\3` `\4`，例如 `\wou\3`、`\hou2\2` (读 hou 的字 + 二声)、`liang\3`。
按《标准卡谋语》的约定，一声不写。渲染器也认识 `\1`，但会画出一声的符号。

### 4. 拼读 (音节)

一个音节 = [声母][1–2 个元音][韵尾]。元音只有 `a e i o u`。音节之间用 `-` 隔开 (`-` 不显示)：

```
sin-gia-pu-la人     kom-piu-ta     san-ti-man-tol-lai-zei-shion
```

- 辅音右上角的小圆圈不用自己画，写成 `sh` `ch` `zh` `ng` `st` 或“辅音 + s” (如 `tsao`、`bats`) 即可。
- 没有声母的音节 (`an`、`out`) 会自动补上占位符。
- 含大写字母的词 (`AI`、`CERN`、`CO2`) 原样显示，不当作拼读。
- 写 `--` 显示一个真正的横线；空格显示为一段空隙。

### 5. 什么时候必须加 `-`

字素名由字母和数字组成，后面紧跟字母或数字时，电脑分不清名字在哪里结束：

| 前面 | 后面 | 加 `-` 吗 | 例子 |
|---|---|---|---|
| 没有声调的字素 | 拟素 (小写字母) | **必须** | `\ou-youz`，不能写 `\ouyouz` |
| 没有声调的字素 | 数字 | **必须** | `\kou-10`，不能写 `\kou10` |
| 有声调的字素 | 拟素或数字 | 可加可不加 | `\wou\3si-mat`、`\wou\3-193` |
| 字素 | 汉字、标点、另一个字素、大写缩写 | 不加 | `\tou学`、`\mi\wou\3` |

写错时渲染器会把读不出来的部分显示成**红色原文**，所以很容易发现。

### 6. 嵌入普通文字：`\kamotish{…}`

在网页、聊天、Markdown 里，把卡谋语部分写在 `\kamotish{` 和 `}` 之间：

```
我叫 \kamotish{ma-tas-jian}，他是 \kamotish{\mi\wou\3中国人\mou\2}。
```

- 括号里要写 `{` `}` `\` 本身时，写成 `\{` `\}` `\\`。
- 括号不能嵌套；没有 `}` 结尾的不处理。
- 有些编辑器 (或 AI 导出的 Markdown) 会把反斜杠写成两个：`\\kamotish{\\mi\\wou\\3}`。这是 Markdown 的转义写法，本仓库的 Markdown 工具会按 `\kamotish{\mi\wou\3}` 处理，不用手动改。
- 想**显示源码而不渲染**：放在代码里 (`` `\kamotish{\mi}` ``)，或者在 `kamotish` 和 `{` 之间加一个空格 (`\kamotish {\mi}`)。

## 二、文档工具：Markdown 预览、修改、导出 PDF

同一个工具有两种打开方式，界面和渲染结果完全一样：

| | 在线版 | 本地版 |
|---|---|---|
| 打开方式 | 浏览器打开 <https://loveprogramming-cc.github.io/kamotish/> | 在电脑上运行 `tools/md2pdf` (见下文)，打开 <http://127.0.0.1:4747> |
| 需要安装 | 不需要 | Node.js 和 Chrome / Edge / Chromium |
| 页面左上角 | 显示“在线版” | 显示“本地版” |
| 加入文件 | 拖入、选择文件、选择文件夹 | 同左，另外可以输入**本机文件夹路径**直接载入 |
| 保存修改 | Chrome / Edge：直接保存回原文件；其他浏览器：下载修改后的 .md | 用路径载入的文件直接保存回原文件；其他同左 |
| 导出 PDF | 浏览器打印窗口 → “存为 PDF” (一次一个) | 一键导出，自动页码；可**全部导出**；可直接存进指定文件夹 |
| 文档里的相对路径图片 | 不显示 | 用路径载入时显示 |
| 联网 | 需要打开网页 | 不需要 |

文件始终只在你的电脑上处理，在线版也不会上传文件。

### 用法 (两个版本相同)

1. **加入文件**：把 .md 文件或整个文件夹拖进左边的框，或点“选择文件”“选择文件夹”。本地版还可以在路径框里输入文件夹的完整路径，点“载入”。
2. **预览**：点列表里的文件，右边显示预览。写错的卡谋语在文件名旁标出“N 处无法渲染”，在预览上方列出 (带行号)，预览里显示成红色。
3. **定位和修改**：点上方列出的某一处错误，会打开左边的源码编辑区并选中那一处源码，右边预览同时滚到对应位置并用橙色框标出。直接修改，右边预览随时更新。“编辑”按钮可以随时打开或关闭编辑区，旁边显示光标所在行号。
4. **保存**：改过的文件名前有 ●。点“保存”或按 ⌘S / Ctrl+S。Chrome / Edge 第一次保存某个文件时会询问是否允许写入，选“允许”。不能写回原文件时，按钮显示“下载修改后的 .md”。有未保存的修改时关闭页面，浏览器会提醒。
5. **设置**：左边选纸张 (A4 / A5 / B5 / Letter) 和字号；本地版还可以选要不要页码。
6. **导出 PDF**：导出的是当前 (包括未保存的修改) 内容。
   - 在线版：点“打印 / 存为 PDF”，在打印窗口里选“存为 PDF”。想要页码，在打印窗口的“更多设置”里勾选“页眉和页脚”。
   - 本地版：点“导出 PDF”，或点“全部导出”导出列表里所有文件。“PDF 存到”留空时由浏览器下载；填一个文件夹的完整路径 (例如 `/Users/你的名字/Documents/PDF`) 时直接存进这个文件夹，**同名 PDF 会被覆盖**，文件夹不存在会自动创建。

另外两个标签页：**试写** (输入卡谋语，实时显示) 和 **下载与说明** (浏览器插件、渲染库)。

### 安装本地版 (只需一次)

需要：

- [Node.js](https://nodejs.org/) 18 或更高版本
- Google Chrome、Microsoft Edge 或 Chromium 中的任意一个。工具只是启动它来打印，不会修改它。装在非标准位置时，用环境变量 `CHROME=/路径/到/浏览器程序` 指定。

```sh
git clone https://github.com/LoveProgramming-cc/kamotish.git
cd kamotish/tools/md2pdf
npm install
npm start            # 然后打开 http://127.0.0.1:4747
```

在 macOS 上也可以直接双击 `tools/md2pdf/启动.command`，它会自动安装依赖并打开页面；关闭那个终端窗口就停止。
服务只监听本机 (`127.0.0.1`)，别的电脑访问不到；它只会写入你用路径载入的 .md 文件，以及你指定的 PDF 文件夹。

### 命令行 (本地版)

```sh
node tools/md2pdf/md2pdf.js 文件.md                    # 生成 文件.pdf (在同一个文件夹)
node tools/md2pdf/md2pdf.js a.md b.md c.md -d 输出文件夹  # 批量
node tools/md2pdf/md2pdf.js 文件.md -o 结果.pdf          # 指定输出文件名
```

选项：`--paper A5` (纸张)、`--size 12` (字号，单位 pt)、`--html` (同时保存中间的 HTML 文件)。
有卡谋语读不出来时，命令行会列出行号和源码。

### Markdown 里能写什么

- 标准 Markdown：标题、列表、表格、粗体、链接、图片、代码、引用、分隔线；也可以直接写 HTML。
- 卡谋语：`\kamotish{…}` (见第一章)。
- 数学公式 (KaTeX)：行内 `$E=mc^2$` 或 `\(E=mc^2\)`；单独一行 `$$…$$` 或 `\[…\]`。
- 语言标为 `latex`、`tex`、`math` 或 `katex` 的代码块 (```` ```latex ````) 也当作单独一行的公式渲染，可以直接写 `\begin{aligned}…\end{aligned}`。想显示 LaTeX 源码本身时，代码块的语言改写成 `text`。

### 关于 PDF 文件大小

每个卡谋语字都以矢量图形写进 PDF，所以卡谋语很多的文档会比较大 (一个单元约 12–20 MB)。好处是任意放大都清晰，打印效果好。

## 三、浏览器插件

安装后，任何网页里的 `\kamotish{…}` 都会显示成卡谋语，跨加粗、链接、换行也能识别。

**输入时预览**：在聊天框、文本框里写 `\kamotish{…}` 时，只要光标在括号里，光标旁就会出现一个小预览框，只显示正在写的这一段 (还没写 `}` 时是淡色)。光标离开括号就消失，也不会挡住正在输入的那一行。按 **Esc** 关闭当前输入框的预览；在插件弹窗的“输入框预览”里可以改成“全部”或“关闭”。

**Chrome / Edge / Brave 等**

1. 下载 `kamotish-chrome.zip` (文档工具的“下载与说明”，或仓库的 `dist/`)，解压成一个文件夹。
2. 打开 `chrome://extensions` (Edge 是 `edge://extensions`)，打开右上角的“开发者模式”。
3. 点“加载已解压的扩展程序”，选择解压出来的文件夹。

**Firefox**

- 临时安装：打开 `about:debugging#/runtime/this-firefox`，点“临时载入附加组件”，选择 `kamotish-firefox.zip` 解压后的 `manifest.json`。重启浏览器后需要重新载入。
- 长期安装：在 addons.mozilla.org 上传 zip 并选择“仅自行分发”即可获得签名。

点工具栏上的插件图标，可以整体开关，或者只在当前网站关闭。本地 `file://` 网页需要在插件详情里打开“允许访问文件网址”。

## 四、在自己的网页或程序里使用

### 渲染库 `kamotish.js`

没有依赖，一个文件即可：

```html
<script src="kamotish.js"></script>

<!-- 方式一：自定义标签，内容就是卡谋语输入 (不需要写 \kamotish{}) -->
<kamo-text>我叫 ma-tas-jian，\mou\1 是字素。</kamo-text>

<!-- 方式二：脚本 -->
<div id="box"></div>
<script>
  Kamotish.mount(document.getElementById('box'), 'ma-tas-jian');
  const html = Kamotish.render('ma-tas-jian');        // 段落 HTML (每个字是一个内联 <svg>)
  const line = Kamotish.renderInline('\\mi\\wou\\3');  // 不分段的 HTML
  Kamotish.parseSyllable('shao');                      // 查看一个音节怎么拆分 (读不出来时抛出错误)
</script>
```

渲染出的文字颜色跟随 CSS 的文字颜色 (`currentColor`)，大小跟随字号 (每个字 1em × 1em)。

### markdown-it 插件

```js
// Node.js
const md = require('markdown-it')().use(require('./web/markdown-it-kamotish.js'), require('./web/kamotish.js').Kamotish);
// 浏览器：先引入 kamotish.js 和 markdown-it-kamotish.js
const md = markdownit().use(window.markdownitKamotish, window.Kamotish);
```

输出的 HTML 需要加上 `Kamotish.css` 这段样式。

## 五、修改字形与重新生成

字形不是字体文件，而是由 `tools/shapes.py` (独立字素和音调的骨架) 和 `tools/forms.py` + `resources/consonants-final/geometry.json` (辅音 A/D 形和位置) 计算出来的。改完以后：

```sh
cd tools
sh build.sh                  # 生成 resources/glyphs-final/、tones-final/
python3 export_js.py         # 生成 web/kamotish.js (JS 版本和 Python 版本使用同一份数据)
python3 build_extension.py   # 更新 extension/ 和 dist/*.zip
python3 test_js_parity.py    # 检查 JS 和 Python 画出的每个点是否一致
```

需要 Python 3 和 Pillow (`pip install pillow`)。文档工具 (在线版和本地版) 都直接使用 `web/kamotish.js` 和 `web/kamotish-markdown.js`，不需要另外更新。推送到 GitHub 后，在线版会自动重新部署。

各中间目录的作用见 [resources/README.md](../resources/README.md)。

## 六、常见问题

**卡谋语显示成红色的字母？**
渲染器读不出这部分。常见原因：没有声调的字素后面紧跟字母或数字却没有加 `-` (如 `\tousi-leep`、`\kou10`)；字素名拼错；音节里有三个连续元音，或声母、韵尾是不支持的辅音组合。

**“他”显示得不对？**
读 hou 的那个字要写 `\hou2`，“他”是 `\hou2\i`。“先生 / 女士”是 `\ka\3\mou2\2`。

**PDF 里没有卡谋语，只有源码？**
检查 `kamotish` 和 `{` 之间是不是多了空格，或者是不是写在了代码 (反引号) 里。这两种写法是故意保留源码用的。

**本地版提示找不到 Chrome？**
安装 Chrome / Edge / Chromium 中的一个，或者用 `CHROME=/路径 npm start` 指定浏览器程序的位置。

**端口 4747 被占用？**
`node server.js 5000` 改用别的端口。
