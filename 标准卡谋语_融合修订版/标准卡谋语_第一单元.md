## 学习指引

- 本书默认读者: 汉语具有小学及以上水平; 英文具有 CET-4 或雅思 5.5 水平。
- 新词汇几乎都来自汉语和英语, 一般不逐个讲解; 由字素构成的词会详细讲解。
- **代入 (代换与嵌套) 是学习曹语的基础。** 每个语法结构都像一个"带空位的模板": 只要类型对得上, 任何短语都可以放进任何空位, 而且可以无限嵌套。学会一个新结构时, 先问自己两个问题: **它的空位接受什么? 它整体是什么?**

# 入门单元 · 文字与发音

---

## 一、曹语是什么

曹语, 又称**卡谋语** (Kamotish)、**曹高远语**, 是一种**分析语**:

- 词汇大部分从**汉语**和**英语**迁移而来, 少量来自日语。
- 句子的"骨架" (语法结构) 由一套专门的字母**字素**书写。
- 词的形式从不变化。对词性的要求也不像英语那样严格, 只要意思明显, 一个词可以跨词性使用。例如 \kamotish{puur} (穷) 可以直接当"穷人"用, 就像英语的 the poor。

**语言的名字本身就是一个曹语短语**:

\kamotish{\e\a\ou\2\e\3言}

| 部分                 | 含义                                  |
| -------------------- | ------------------------------------- |
| \kamotish{\e\a\ou\2} | 用字素拼出的"曹" (拼法见本单元第七节) |
| \kamotish{\e\3}      | "……的" (第 2 课学习)                  |
| \kamotish{言}        | 语言                                  |

合起来是"曹的语言", 即曹语。

**小知识**: "卡谋语"这个名字来自 \kamotish{\ka\3\mou2\2} (kǎ móu, "先生/女士") 的发音 (第 1 课学习)。

## 二、三种文字

曹语同时使用三种文字:

| 文字     | 用途                                                          | 例                                                                                                     |
| -------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **字素** | 句子主干 (语法结构)、人称代词、人名地名、少数专有词与固定短语 | \kamotish{\mi} (我)、\kamotish{\wou\3} (是)、\kamotish{\kou\hou2\mou\2} (你好)、\kamotish{\a\i\4} (爱) |
| **汉字** | 来自汉语的词汇                                                | \kamotish{犬} (狗)、\kamotish{学} (学习)、\kamotish{中国}                                              |
| **拟素** | 来自外语的词汇、拟声词                                        | \kamotish{si-mat} (smart, 聪明)、\kamotish{cait} (cat, 猫)                                             |

汉字和拟素可以连在一起组成一个词, 例如 \kamotish{sin-gia-pu-la人} (新加坡人)。

一个完整的句子:

\kamotish{\mi\wou\3si-mat\mou\2} (我很聪明。)

其中 \kamotish{\mi} (我)、\kamotish{\wou\3} (是)、\kamotish{\mou\2} (语气词) 是字素, \kamotish{si-mat} (聪明) 是拟素。

## 三、字素 · 30音图

每个字素有三个属性:

1. **字形**
2. **读音**: 它作为语法结构使用时的读法。
3. **身份**: 它对应的拉丁字母。身份用于组成拟素 (模拟外来语发音) 和拼写人名地名。

| 行  | 字素            | 读音     | 身份       |     | 字素            | 读音 | 身份 |
| --- | --------------- | -------- | ---------- | --- | --------------- | ---- | ---- |
| ①   | \kamotish{\wou} | wou      | w          |     | \kamotish{\ha}  | ha   | l    |
| ①   | \kamotish{\mi}  | mi / hou | h          |     | \kamotish{\mou} | mou  | m    |
| ①   | \kamotish{\tou} | tou      | t          |     |                 |      |      |
| ②   | \kamotish{\wu}  | wu       | d          |     | \kamotish{\e}   | e    | c    |
| ②   | \kamotish{\sou} | sou / le | s          |     | \kamotish{\ou}  | ou   | o    |
| ②   | \kamotish{\kou} | kou      | k          |     |                 |      |      |
| ③   | \kamotish{\bi}  | bi       | b          |     | \kamotish{\ga}  | ga   | g    |
| ③   | \kamotish{\ku}  | ku       | p          |     | \kamotish{\lou} | lou  | n    |
| ③   | \kamotish{\hou} | hou      | q          |     |                 |      |      |
| ④   | \kamotish{\yu}  | yu       | e          |     | \kamotish{\chi} | chi  | y    |
| ④   | \kamotish{\te}  | te       | (无)       |     | \kamotish{\pou} | pou  | v    |
| ⑤   | \kamotish{\a}   | a        | a          |     | \kamotish{\ka}  | ka   | f    |
| ⑤   | \kamotish{\ri}  | ri / mou | r          |     | \kamotish{\bou} | bou  | u    |
| ⑤   | \kamotish{\nou} | nou      | (无)       |     |                 |      |      |
| ⑥   | \kamotish{\sei} | sei      | (无)       |     | \kamotish{\shi} | shi  | z    |
| ⑥   | \kamotish{\zhi} | zhi      | x          |     | \kamotish{\i}   | i    | i    |
| ⑥   | \kamotish{\xi}  | xi       | j          |     |                 |      |      |
| ⑦   | \kamotish{\ii}  | ii       | (无, 占位) |     |                 |      |      |

要点:

1. 21 个英文辅音字母各有一个字素作为身份。
2. 元音 a、e、i、o、u 也各有身份字素: \kamotish{\a}、\kamotish{\yu}、\kamotish{\i}、\kamotish{\ou}、\kamotish{\bou}。**注意: 身份为 e 的字素读 yu; 读 e 的字素 \kamotish{\e} 身份却是 c。**
3. \kamotish{\te}、\kamotish{\nou}、\kamotish{\sei} 没有身份, 只作语法结构使用。
4. 第 ⑦ 行的 \kamotish{\ii} 没有身份, 在拟素中作**占位符**, 表示"没有首辅音"。

### 有两个读音的字素

有三个字素各有两个读音:

| 字素            | 通常读          | 也读 | 读第二个音的例子                                           |
| --------------- | --------------- | ---- | ---------------------------------------------------------- |
| \kamotish{\mi}  | mi              | hou  | \kamotish{\hou2\i} (他)、\kamotish{\kou\hou2\mou\2} (你好) |
| \kamotish{\sou} | sou             | le   | \kamotish{\wu\2\le\4} (正式否定)                           |
| \kamotish{\ri}  | ri (发 li 的音) | mou  | \kamotish{\ka\3\mou2\2} (先生/女士)                        |

在大多数情况下, 它们读通常的读音。读另一个音的情况会在课文中逐个说明。刚开始学习时, 可以先认为它们总是读 mi、sou、ri。

注意 \kamotish{\hou2\i} (他) 中读 hou 的字, 和 \kamotish{\hou} 是**两个不同的字**; \kamotish{\ka\3\mou2\2} 中读 mou 的字, 和 \kamotish{\mou} 也是**两个不同的字**。请对照字形区分。

## 四、声调

- 字素作为语法结构使用时有声调, 共四个: 一声、二声、三声、四声。
- 声调符号写在字素的**右上角**。一声在课文中通常不标。
- 汉字按普通话的声调读; 拟素没有声调。
- **声调能区分意思**。例如 \kamotish{\wou\3} (三声) 是"是", 而 \kamotish{\wou} (一声) 是另一个语法结构 (第 15 课学习)。

| 字素                    | 读音      |
| ----------------------- | --------- |
| \kamotish{\wou\3}       | wǒu       |
| \kamotish{\mou\2}       | móu       |
| \kamotish{\pou\2\chi\4} | póu chì   |
| \kamotish{\wu\2\le\4}   | wú lè     |
| \kamotish{\mi}          | mi (一声) |

## 五、汉字

### 5.1 读法

- 基本按普通话拼音读。
- 有一定的变音规则, 例如 y 变成 gi (牙 ya → gia), 但完全可以照普通话读。更多规则在后文讲解。

### 5.2 用法

- **尽量只用一个汉字**, 带有文言的感觉:

| 中文 | 曹语          |
| ---- | ------------- |
| 狗   | \kamotish{犬} |
| 笑脸 | \kamotish{靥} |
| 名字 | \kamotish{名} |
| 朋友 | \kamotish{友} |
| 母亲 | \kamotish{母} |
| 宿舍 | \kamotish{舍} |

- 多字的概念**不拼成复合词**, 而是用语法结构把单字连起来:

| 中文     | 曹语                  | 不要写成 |
| -------- | --------------------- | -------- |
| 今天中午 | \kamotish{今\e\3午}   | 今午     |
| 早上六点 | \kamotish{晨\e\3六时} | 晨六时   |

- 少数专有名词 (国名、校名) 可以用多个汉字: \kamotish{中国}、\kamotish{北京学院}。
- **汉英选择原则**: 汉字词和英语词哪个写出来短, 就用哪个。例如 grammar、progress 转写出来太长, 就用 \kamotish{法} (语法)、\kamotish{进} (进步)。但整体上, 英语来源的词应该占较大比例。

## 六、拟素 (外来语)

### 6.1 拟素的结构

一个拟素是一个"字块", 最多由四部分组成, 按 A → B → C → D 的顺序发音:

```
 ┌─────┐ ┃
 │  A  │ ┃ ← B 主元音 (竖元音, 竖写在 A 旁边)
 └─────┘ ┃
 ━━━━━━━━━━ ← C 次元音 (横元音, 横写在 A、B 下方)
 ┌─────────┐
 │    D    │ ← D 末辅音
 └─────────┘
```

| 部分 | 名称   | 写法                 | 是否必需                            |
| ---- | ------ | -------------------- | ----------------------------------- |
| A    | 首辅音 | 字素 (取其身份)      | 可选; 没有时写占位符 \kamotish{\ii} |
| B    | 主元音 | 竖元音 a、e、i、o、u | **必需**                            |
| C    | 次元音 | 横元音 a、e、i、o、u | 可选                                |
| D    | 末辅音 | 字素 (取其身份)      | 可选                                |

| 例              | A      | B   | C   | D   |
| --------------- | ------ | --- | --- | --- |
| \kamotish{duit} | d      | u   | i   | t   |
| \kamotish{out}  | (占位) | o   | u   | t   |
| \kamotish{xin}  | x      | i   | —   | n   |
| \kamotish{mou}  | m      | o   | u   | —   |
| \kamotish{ku}   | k      | u   | —   | —   |

### 6.2 加 ° (s 化)

在辅音的右上角加 °, 会改变它的读音:

| 情况                   | 效果                           | 例                                 |
| ---------------------- | ------------------------------ | ---------------------------------- |
| 一般辅音加 °           | 后面加 s                       | \kamotish{tao} → \kamotish{tsao}   |
| s、c、z 作首辅音时加 ° | 变成 sh、ch、zh                | \kamotish{sao} → \kamotish{shao}   |
| c、z 在词末            | **不能**加 °; 想发 cs, 请用 ks |                                    |
| n 作末辅音时加 °       | 变成 ng                        | \kamotish{xin} → \kamotish{xing}   |
| 末尾是 ns、ngs         | 把 s 拆出来单独写              | \kamotish{xins}                    |
| s 作末辅音时加 °       | 变成 st                        | \kamotish{mois} → \kamotish{moist} |

### 6.3 合法的音节

每个音节 = (前辅音) + 元音 + (后辅音), **至少要有一个元音**。

| 部分   | 是否必需 | 规则                                   | 合法                  | 不合法              |
| ------ | -------- | -------------------------------------- | --------------------- | ------------------- |
| 前辅音 | 可选     | 1 个辅音 (或 sh、zh、ch), 后面可再加 s | b、ks、ds、zh         | cd、kk、sk、kl、str |
| 元音   | **必需** | 1–2 个, 只能是 a、e、i、o、u           | a、ii、ai、ou、oo     | iou (3 个)          |
| 后辅音 | 可选     | 1 个辅音 (或 st、ng), 后面可再加 s     | m、st、ts、ks、ng、ls | dd、sh、ch、nt      |

- 合法: \kamotish{i}、\kamotish{ai}、\kamotish{hiu}、\kamotish{ing}、\kamotish{shou}、\kamotish{shoung}
- 不合法: sking (前辅音不合法)、lng (没有元音)、hious (元音太多)

### 6.4 按发音转写

外来语要**按实际发音转写, 不按拼写**。曹语的发音系统与汉语拼音相似, 所以转写听起来带有中文口音。

| 英语发音       | 转写                   | 例                                                                       |
| -------------- | ---------------------- | ------------------------------------------------------------------------ |
| tr             | ch                     | tree → \kamotish{chui}                                                   |
| dr             | zh                     | dream → \kamotish{zhuim}                                                 |
| str            | si + zh                | strong → \kamotish{si-zhuang}                                            |
| th             | s                      | health → \kamotish{hails}; three → \kamotish{si-rui}                     |
| 辅音后的 r     | 变成 u                 | tree → \kamotish{chui}; rich → \kamotish{rui-chi}                        |
| 弱读元音       | o                      | banana → \kamotish{bo-nan-na} (不是 ba-na-na)                            |
| 短 e           | a 或 ai (看后面的辅音) | sentimental → \kamotish{san-ti-man-tol}; health → \kamotish{hails}       |
| -tal           | tol                    | sentimental → \kamotish{san-ti-man-tol}                                  |
| -ful           | fuo / foul             | powerful → \kamotish{pou-wer-fuo}; successful → \kamotish{sek-seis-foul} |
| 不合法的辅音丛 | 拆开, 插入元音         | Claude → \kamotish{ke-lod}; speak → \kamotish{si-piik}                   |
| 词尾的 ch      | 拆成 chi               | teach → \kamotish{tii-chi}                                               |

**完整示范**: sentimentalization (感伤化)

1. 划分音节: sen、ti、men、tal、li、za、tion
2. 按曹语发音习惯模拟: san、ti、man、tol、lai、zei、shion
3. 逐个写成拟素: \kamotish{san-ti-man-tol-lai-zei-shion}

只要按以上规则从英语转写, 得到的就是正确的曹语词。

### 6.5 拟素的其他用途

- **拟声词**, 例如猫叫声。
- 与汉字连写成一个词: \kamotish{sin-gia-pu-la人} (新加坡人)、\kamotish{ni-hong人} (日本人)。

---

## 七、人名与地名

### 7.1 写汉字

最简单的写法是写汉字 (如果有的话), 读法和汉语一样: \kamotish{李}、\kamotish{王}、\kamotish{中国}、\kamotish{北京}。

### 7.2 用字素拼写

也可以把拼音的每个字母换成**身份**相同的字素, 按顺序排列, 然后在**最后一个字素**上加上这个字的声调。

**例: 王 (wáng, 二声)**

| 字母 | w               | a             | n               | g              |
| ---- | --------------- | ------------- | --------------- | -------------- |
| 字素 | \kamotish{\wou} | \kamotish{\a} | \kamotish{\lou} | \kamotish{\ga} |

最后一个字素加二声 → \kamotish{\wou\a\lou\ga\2}, 读作 wou a lou gá。

更多例子:

| 人名 | 拼音  | 写法                        | 读音            |
| ---- | ----- | --------------------------- | --------------- |
| 曹   | cáo   | \kamotish{\e\a\ou\2}        | e a óu          |
| 微   | wēi   | \kamotish{\wou\yu\i}        | wou yu i        |
| 李   | lǐ    | \kamotish{\ha\i\3}          | ha ǐ            |
| 张   | zhāng | \kamotish{\shi\mi\a\lou\ga} | shi mi a lou ga |

### 7.3 外语人名

本书的外语人名主要用字素拼写, **不加声调**:

| 人名        | 写法                           | 读音               |
| ----------- | ------------------------------ | ------------------ |

### 7.4 国名、地名

外国的国名、地名一般用拟素:

## 三、语法详解

### 1. 人称代词: \kamotish{\mi} 与 \kamotish{\yu}

| 曹语           | 中文 |
| -------------- | ---- |
| \kamotish{\mi} | 我   |
| \kamotish{\yu} | 你   |

本课只学第一人称和第二人称。"他""她""我们"等在第 2 课学习。

### 2. A\kamotish{\wou\3}B: A 是 B

这是曹语最基本的句型。

**(1) 基本意思**

A\kamotish{\wou\3}B 的意思是"A 是 B"。

**1.** \kamotish{\mi\wou\3人\mou\2}  
　　发音: *mi wǒu rén móu*  
　　译文: 我是人。

**2.** \kamotish{\yu\wou\3AI\mou\2}  
　　发音: *yu wǒu AI móu*  
　　译文: 你是 AI。

**3.** \kamotish{犬\wou\3兽\mou\2}  
　　发音: *quǎn wǒu shòu móu*  
　　译文: 狗是动物。

**(2) A 和 B 可以是什么?**

A 和 B 可以是名词, 也可以是形容词, 还可以是后面要学的各种短语。总之, **除了句子本身以外, 几乎什么都可以**。

当 B 是形容词时, 中文常常翻译成"A 很 B":

**4.** \kamotish{\mi\wou\3si-mat\mou\2}  
　　发音: *mi wǒu si mat móu*  
　　译文: 我很聪明。

**5.** \kamotish{\yu\wou\3喜\mou\2}  
　　发音: *yu wǒu xǐ móu*  
　　译文: 你很开心。

**6.** \kamotish{犬\wou\3kiut\mou\2}  
　　发音: *quǎn wǒu kiut móu*  
　　译文: 狗很可爱。

**(3) 代入法**

造句时, 先想清楚 A 和 B 分别是什么, 再把它们放进句型:

| 中文           | A              | B                          | 曹语                                      |
| -------------- | -------------- | -------------------------- | ----------------------------------------- |
| 我是中国人。   | \kamotish{\mi} | \kamotish{中国人}          | \kamotish{\mi\wou\3中国人\mou\2}          |
| 你是美国人。   | \kamotish{\yu} | \kamotish{aa-mei-li-ka人}  | \kamotish{\yu\wou\3aa-mei-li-ka人\mou\2}  |
| 我是新加坡人。 | \kamotish{\mi} | \kamotish{sin-gia-pu-la人} | \kamotish{\mi\wou\3sin-gia-pu-la人\mou\2} |

**尝试一下**: "你是韩国人"怎么说?

答案: \kamotish{\yu\wou\3han-guk人\mou\2}

**(4) 句子不能再放进 A 或 B**

A\kamotish{\wou\3}B 构成一个独立的句子。一个独立的句子**不能**再放进另一个句型的 A 或 B 中。以后学到"从句"时, 我们会学习怎样把句子变成可以放进去的形式。

### 3. 人名 + \kamotish{\ka\3\mou2\2}: ～先生 / ～女士

**(1) 用法**

\kamotish{\ka\3\mou2\2} 接在人名后面, 是礼貌、亲切的称呼, 类似日语的「さん」。它**不分男女**, 所以既可以译成"先生", 也可以译成"女士"。

| 曹语                               | 中文     |
| ---------------------------------- | -------- |
| \kamotish{王\ka\3\mou2\2}          | 王先生   |
| \kamotish{李\ka\3\mou2\2}          | 李女士   |
| \kamotish{\kou\i\mou\ka\3\mou2\2}  | Kim 女士 |
| \kamotish{\tou\ou\mou\ka\3\mou2\2} | Tom 先生 |

**(2) 读音**

\kamotish{\ka\3\mou2\2} 读作 kǎ móu。这里的第二个字和 \kamotish{\ri} 是同一个字, 通常读 ri, 但在 \kamotish{\ka\3\mou2\2} 中读 mou。

**(3) 放进句子**

"人名 + \kamotish{\ka\3\mou2\2}"整体是一个名词, 所以可以放进 A\kamotish{\wou\3}B 的 A, 也可以放进 B:

**1.** \kamotish{\tou\ou\mou\ka\3\mou2\2\wou\3aa-mei-li-ka人\mou\2}  
　　发音: *tou ou mou kǎ móu wǒu aa mei li ka rén móu*  
　　译文: Tom 先生是美国人。

**2.** \kamotish{\mi\wou\3\tou\ou\mou\ka\3\mou2\2\mou\2}  
　　发音: *mi wǒu tou ou mou kǎ móu móu*  
　　译文: 我就是 Tom。

第二句中, \kamotish{\tou\ou\mou\ka\3\mou2\2} 在 B 的位置上。说自己的名字时, 也可以不加 \kamotish{\ka\3\mou2\2}: \kamotish{\mi\wou\3\tou\ou\mou\mou\2}。

**小知识**: "卡谋语"的名字正是来自 \kamotish{\ka\3\mou2\2} 的读音。

### 4. 语气词

说完一段话, 最后一句话的末尾应该加上一个**语气词**。语气词可以缓和语气, 也可以表达正式感。曹语有四个基本的语气词:

|               | 肯定                    | 否定                              |
| ------------- | ----------------------- | --------------------------------- |
| 一般 (非正式) | \kamotish{\mou\2}       | \kamotish{\bou\3\mou\2}           |
| 正式          | \kamotish{\pou\2\chi\4} | \kamotish{\pou\2\chi\4\wu\2\le\4} |

#### (1) \kamotish{\mou\2}: 一般的肯定语气

A\kamotish{\wou\3}B 本身已经是肯定的"A 是 B", 但在最后一句话的末尾, 仍然应该加上 \kamotish{\mou\2}。

**1.** \kamotish{\mi\wou\3中国人\mou\2}  
　　发音: *mi wǒu zhōng guó rén móu*  
　　译文: 我是中国人。

**只有最后一句加**。如果一次说了好几句话, 前面的句子不加 \kamotish{\mou\2}:

**2.** \kamotish{\mi\wou\3中国人,\yu\wou\3ni-hong人\mou\2}  
　　发音: *mi wǒu zhōng guó rén, yu wǒu ni hong rén móu*  
　　译文: 我是中国人, 你是日本人。

第一句 \kamotish{\mi\wou\3中国人} 不是最后一句, 所以末尾不加。

#### (2) \kamotish{\bou\3\mou\2}: 一般的否定语气

把句末的 \kamotish{\mou\2} 换成 \kamotish{\bou\3\mou\2}, 整个句子就变成了否定:

| 肯定                                    | 否定                                          |
| --------------------------------------- | --------------------------------------------- |
| \kamotish{犬\wou\3兽\mou\2} 狗是动物。  | \kamotish{犬\wou\3人\bou\3\mou\2} 狗不是人。  |
| \kamotish{\mi\wou\3喜\mou\2} 我很开心。 | \kamotish{\mi\wou\3喜\bou\3\mou\2} 我不开心。 |

如果有好几个否定句, **前面的句子末尾用 \kamotish{\bou\3}, 只有最后一句用 \kamotish{\bou\3\mou\2}**:

**3.** \kamotish{\mi\wou\3han-guk人\bou\3,\yu\wou\3ni-hong人\bou\3\mou\2}  
　　发音: *mi wǒu han guk rén bǒu, yu wǒu ni hong rén bǒu móu*  
　　译文: 我不是韩国人, 你不是日本人。

如果两个句子的主语相同, 后一句可以省略主语:

**4.** \kamotish{李\ka\3\mou2\2\wou\3ya-xi-ya人\bou\3,\wou\3au-si-zhui-li-ya人\bou\3\mou\2}  
　　发音: *lǐ kǎ móu wǒu ya xi ya rén bǒu, wǒu au si zhui li ya rén bǒu móu*  
　　译文: 李女士不是亚洲人, 也不是澳大利亚人。

#### (3) \kamotish{\pou\2\chi\4}: 正式的肯定语气

用于正式场合、书面语, 或对长辈、老师说话。和 \kamotish{\mou\2} 一样, **只加在最后一句**:

**5.** \kamotish{\kou\i\mou\ka\3\mou2\2\wou\3han-guk人\pou\2\chi\4}  
　　发音: *kou i mou kǎ móu wǒu han guk rén póu chì*  
　　译文: Kim 女士是韩国人。

**6.** \kamotish{\mi\wou\3中国人,\yu\wou\3sin-gia-pu-la人\pou\2\chi\4}  
　　发音: *mi wǒu zhōng guó rén, yu wǒu sin gia pu la rén póu chì*  
　　译文: 我是中国人, 您是新加坡人。

#### (4) \kamotish{\pou\2\chi\4\wu\2\le\4}: 正式的否定语气

这个语气词和前三个不同: **如果每一句都是否定的, 每一句的末尾都要加上它。**

**7.** \kamotish{\mi\wou\3ni-hong人\pou\2\chi\4\wu\2\le\4,\yu\wou\3aa-mei-li-ka人\pou\2\chi\4\wu\2\le\4}  
　　发音: *mi wǒu ni hong rén póu chì wú lè, yu wǒu aa mei li ka rén póu chì wú lè*  
　　译文: 我不是日本人, 你不是美国人。

如果否定句后面接一个肯定句, 也是各加各的:

**8.** \kamotish{\mi\wou\3香港人\pou\2\chi\4\wu\2\le\4,台湾人\pou\2\chi\4。}  
　　发音: *mi wǒu hōng kōng rén póu chì wú lè, tái wān rén póu chì.*  
　　译文: 我不是香港人, 而是台湾人。

第二句"台湾人"前面省略了 \kamotish{\mi\wou\3}, 因为主语相同。

#### (5) 小结

|                                   | 加在哪里                                         |
| --------------------------------- | ------------------------------------------------ |
| \kamotish{\mou\2}                 | 一段话的最后一句                                 |
| \kamotish{\pou\2\chi\4}           | 一段话的最后一句                                 |
| \kamotish{\bou\3\mou\2}           | 最后一个否定句; 前面的否定句用 \kamotish{\bou\3} |
| \kamotish{\pou\2\chi\4\wu\2\le\4} | 每一个否定句                                     |

语气词还有许多更微妙的作用, 后面会逐步介绍。

### 5. 一般疑问句

#### (1) 正式: \kamotish{\pou\2\chi\4\a\shi\2}

在陈述句末尾的 \kamotish{\pou\2\chi\4} 后面再加上 \kamotish{\a\shi\2}, 就变成了正式的疑问句:

| 陈述                                                                | 疑问                                                                        |
| ------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| \kamotish{\yu\wou\3中国人\pou\2\chi\4} 您是中国人。                 | \kamotish{\yu\wou\3中国人\pou\2\chi\4\a\shi\2?} 您是中国人吗?               |
| \kamotish{\e\a\ou\2\ka\3\mou2\2\wou\3喜\pou\2\chi\4} 曹先生很开心。 | \kamotish{\e\a\ou\2\ka\3\mou2\2\wou\3喜\pou\2\chi\4\a\shi\2?} 曹先生开心吗? |

**注意**: 正式的疑问句必须是 \kamotish{\pou\2\chi\4} + \kamotish{\a\shi\2}, 不能只加 \kamotish{\a\shi\2}。

#### (2) 非正式: 很随意

非正式的疑问句, 在句末加 \kamotish{\shi\2}、\kamotish{\a\shi\2}、\kamotish{\mou\2\shi\2} 中的任何一个都可以, **意思没有区别**:

| 写法                                | 意思      |
| ----------------------------------- | --------- |
| \kamotish{\yu\wou\3喜\shi\2?}       | 你开心吗? |
| \kamotish{\yu\wou\3喜\a\shi\2?}     | 你开心吗? |
| \kamotish{\yu\wou\3喜\mou\2\shi\2?} | 你开心吗? |

#### (3) 回答

| 曹语                      | 意思       | 说明     |
| ------------------------- | ---------- | -------- |
| \kamotish{\lou\3\lou\3}   | 是的; 当然 | 单独成句 |
| \kamotish{\bou\3\bou\3}   | 不; 不是   | 单独成句 |
| \kamotish{知\wu\2\le\4}   | 不知道     | 较正式   |
| \kamotish{\bou\3知\mou\2} | 不知道     | 不太正式 |

回答之后, 可以再补充一句完整的话:

**1.** \kamotish{\lou\3\lou\3。\mi\wou\3中国人\mou\2。}  
　　发音: *lǒu lǒu. mi wǒu zhōng guó rén móu.*  
　　译文: 是的。我是中国人。

**2.** \kamotish{\bou\3\bou\3。\mi\wou\3台湾人\mou\2。}  
　　发音: *bǒu bǒu. mi wǒu tái wān rén móu.*  
　　译文: 不。我是台湾人。

### 6. 日常用语: \kamotish{\kou\hou2\mou\2}

\kamotish{\kou\hou2\mou\2} 是"你好"。这里的第二个字和 \kamotish{\mi} 是同一个字, 但在这里读 hou。所以 \kamotish{\kou\hou2\mou\2} 读作 kou hou móu。

它是一个固定短语, 见面时直接说即可。

## 四、应用课文

### 应用课文一: 你好

新学期第一天, 王在教室里遇见了 Teo。

**王**: \kamotish{\kou\hou2\mou\2!\mi\wou\3王\mou\2。}  
　　*kou hou móu! mi wǒu wáng móu.*  
　　(你好! 我是王。)

**Teo**: \kamotish{\kou\hou2\mou\2!\mi\wou\3\tou\yu\ou\mou\2。}  
　　*kou hou móu! mi wǒu tou yu ou móu.*  
　　(你好! 我是 Teo。)

**王**: \kamotish{\yu\wou\3中国人\shi\2?}  
　　*yu wǒu zhōng guó rén shí?*  
　　(你是中国人吗?)

**Teo**: \kamotish{\bou\3\bou\3。\mi\wou\3sin-gia-pu-la人\mou\2。}  
　　*bǒu bǒu. mi wǒu sin gia pu la rén móu.*  
　　(不是。我是新加坡人。)

### 应用课文二: 老师来了

曹老师走进教室。

**曹老师**: \kamotish{\kou\hou2\mou\2!\mi\wou\3\e\a\ou\2\pou\2\chi\4。}  
　　*kou hou móu! mi wǒu e a óu póu chì.*  
　　(大家好! 我是曹。)

**Sakura**: \kamotish{\e\a\ou\2\ka\3\mou2\2\wou\3中国人\pou\2\chi\4\a\shi\2?}  
　　*e a óu kǎ móu wǒu zhōng guó rén póu chì a shí?*  
　　(曹先生是中国人吗?)

**曹老师**: \kamotish{\lou\3\lou\3。\yu\wou\3ni-hong人\shi\2?}  
　　*lǒu lǒu. yu wǒu ni hong rén shí?*  
　　(是的。你是日本人吗?)

**Sakura**: \kamotish{\lou\3\lou\3。\mi\wou\3ni-hong人\pou\2\chi\4。}  
　　*lǒu lǒu. mi wǒu ni hong rén póu chì.*  
　　(是的。我是日本人。)

**曹老师**: \kamotish{\yu\wou\3han-guk人\shi\2?}  
　　*yu wǒu han guk rén shí?*  
　　((对 Kim) 你是韩国人吗?)

**Kim**: \kamotish{\lou\3\lou\3,\mi\wou\3han-guk人\pou\2\chi\4。}  
　　*lǒu lǒu, mi wǒu han guk rén póu chì.*  
　　(是的, 我是韩国人。)

### 应用课文三: 他是谁?

李看见一位不认识的同学。

**李**: \kamotish{\yu\wou\3aa-mei-li-ka人\shi\2?}  
　　*yu wǒu aa mei li ka rén shí?*  
　　(你是美国人吗?)

**Tom**: \kamotish{\lou\3\lou\3。\yu\wou\3ni-hong人\shi\2?}  
　　*lǒu lǒu. yu wǒu ni hong rén shí?*  
　　(是的。你是日本人吗?)

**李**: \kamotish{\bou\3\bou\3。\mi\wou\3台湾人\mou\2。}  
　　*bǒu bǒu. mi wǒu tái wān rén móu.*  
　　(不是。我是台湾人。)

**Tom**: \kamotish{\yu\wou\3si-mat\shi\2?}  
　　*yu wǒu si mat shí?*  
　　(你聪明吗?)

**李**: \kamotish{\bou\3知\mou\2!}  
　　*bǒu zhī móu!*  
　　(不知道!)

## 五、说明

1. **对老师用正式语气**: 应用课文二中, Sakura 问老师问题时用了 \kamotish{\pou\2\chi\4\a\shi\2}, 回答时用了 \kamotish{\pou\2\chi\4}; 老师对学生说话用非正式的 \kamotish{\shi\2}。
2. **老师自我介绍时用了 \kamotish{\pou\2\chi\4}**, 因为在课堂上说话比较正式。
3. **应答词后面再补充一句**: 李先用 \kamotish{\bou\3\bou\3} 回答, 再说一句完整的话 \kamotish{\mi\wou\3台湾人\mou\2}。
4. **李的"不知道"**: Tom 开玩笑地问李聪不聪明, 李也开玩笑地用不太正式的 \kamotish{\bou\3知\mou\2} 回答。

## 三、语法详解

### 1. A\kamotish{\e\3}B: A 的 B

**(1) 基本意思**

A\kamotish{\e\3}B 表示 **B 属于 A**, 译作"A 的 B"。A 和 B 都必须是名词。

| 曹语                 | 中文     |
| -------------------- | -------- |
| \kamotish{\mi\e\3友} | 我的朋友 |
| \kamotish{\yu\e\3母} | 你的妈妈 |
| \kamotish{王\e\3車}  | 王的车   |
| \kamotish{\mi\e\3名} | 我的名字 |

**(2) 中心是 B**

A\kamotish{\e\3}B 里有两个名词, 那么整个短语"说的是"哪一个?

想一想中文的"我的车很大": 是"我"很大, 还是"车"很大? 显然是车。A\kamotish{\e\3}B 也一样: **当它放进句子里时, 被叙述的是 B, A 只是对 B 的修饰。** 我们说 A\kamotish{\e\3}B 是"代表 B 的名词短语"。

**1.** \kamotish{\mi\e\3車\wou\3宏\mou\2}  
　　发音: *mi ě chē wǒu hóng móu*  
　　译文: 我的车很大。(大的是车)

**2.** \kamotish{\mi\e\3車\wou\3红\pou\2\chi\4}  
　　发音: *mi ě chē wǒu hóng póu chì*  
　　译文: 我的车是红色的。

**(3) 放进 A\kamotish{\wou\3}B**

A\kamotish{\e\3}B 整体是一个名词, 所以它可以放进 A\kamotish{\wou\3}B 的 A 或 B:

| 放在哪里 | 例                                                     | 意思                 |
| -------- | ------------------------------------------------------ | -------------------- |
| A        | \kamotish{\mi\e\3母\wou\3中国人\mou\2}                 | 我的妈妈是中国人。   |
| B        | \kamotish{\tou\yu\ou\ka\3\mou2\2\wou\3\mi\e\3友\mou\2} | Teo 先生是我的朋友。 |
| A 和 B   | \kamotish{\yu\e\3友\wou\3\mi\e\3友\mou\2}              | 你的朋友是我的朋友。 |

**尝试一下**: "王的妈妈是我的老师"怎么说?

提示: A 是"王的妈妈" \kamotish{王\e\3母}, B 是"我的老师"。

答案: \kamotish{王\e\3母\wou\3\mi\e\3授\xi\2\mou\2}

### 2. A\kamotish{\xi\2}: 做 A 的人

**(1) 基本意思**

A 是一个动词, A\kamotish{\xi\2} 表示"做 A 这件事的人", 整体是一个名词。

| 动词                 | 加 \kamotish{\xi\2}  | 意思                |
| -------------------- | -------------------- | ------------------- |
| \kamotish{学} 学习   | \kamotish{学\xi\2}   | 学习的人 → **学生** |
| \kamotish{授} 教     | \kamotish{授\xi\2}   | 教的人 → **老师**   |
| \kamotish{著} 写作   | \kamotish{著\xi\2}   | 写作的人 → **作者** |
| \kamotish{阅} 阅读   | \kamotish{阅\xi\2}   | 阅读的人 → **读者** |
| \kamotish{领导} 领导 | \kamotish{领导\xi\2} | 领导的人 → **领导** |

**(2) "者"**

讲义中也写作 \kamotish{学\xi\2者}、\kamotish{授\xi\2者}, 但"者"**通常省略**。本书一般不写"者"。

**(3) 放进句子**

**1.** \kamotish{\yu\wou\3学\xi\2\mou\2}  
　　发音: *yu wǒu xué xí móu*  
　　译文: 你是学生。

**2.** \kamotish{\mi\e\3父\wou\3著\xi\2\pou\2\chi\4}  
　　发音: *mi ě fù wǒu zhù xí póu chì*  
　　译文: 我的父亲是作者。

\kamotish{\xi\2} 前面不仅可以是一个动词, 还可以是一个"动词短语" (例如"吃饭""爱你"), 这在第 5 课学习。

### 3. \kamotish{\lou\3}A: 复数

**(1) 基本意思**

A 是名词, \kamotish{\lou\3}A 表示"多个 A", 或者"A 作为一个群体"。

| A                       | \kamotish{\lou\3}A              |
| ----------------------- | ------------------------------- |
| \kamotish{\mi} 我       | \kamotish{\lou\3\mi} 我们       |
| \kamotish{\yu} 你       | \kamotish{\lou\3\yu} 你们       |
| \kamotish{学\xi\2} 学生 | \kamotish{\lou\3学\xi\2} 学生们 |
| \kamotish{cait} 猫      | \kamotish{\lou\3cait} 猫们      |

**(2) 不要求单复数一致**

"你们是学生"中, 主语是复数, 但 B 不必也变成复数, 保留 \kamotish{学\xi\2} 即可:

**1.** \kamotish{\lou\3\yu\wou\3学\xi\2\mou\2}  
　　发音: *lǒu yu wǒu xué xí móu*  
　　译文: 你们是学生。

当然, \kamotish{\lou\3\yu\wou\3\lou\3学\xi\2\pou\2\chi\4} 也是对的, 而且在正式场合更推荐这样说。

**(3) \kamotish{\lou\3} 的位置决定意思**

\kamotish{\lou\3} 只管它**后面紧接着**的那个名词:

| 曹语                               | 意思         |
| ---------------------------------- | ------------ |
| \kamotish{\lou\3\yu\e\3cait}       | **你们**的猫 |
| \kamotish{\yu\e\3\lou\3cait}       | 你的**猫们** |
| \kamotish{\lou\3\yu\e\3\lou\3cait} | 你们的猫们   |

### 4. 第三人称

| 曹语                   | 意思           | 说明                                             |
| ---------------------- | -------------- | ------------------------------------------------ |
| \kamotish{\hou2\i}     | 他             | 第一个字和 \kamotish{\mi} 是同一个字, 这里读 hou |
| \kamotish{\sou\hou2\i} | 她             | 比"他"多一个 \kamotish{\sou}                     |
| \kamotish{其}          | 它; 也可以指人 | 汉字                                             |
| \kamotish{\ku\i}       | ta             | 不区分性别, 也不区分人和物, 依上下文理解         |

复数都加 \kamotish{\lou\3}:

| 曹语                         | 意思       |
| ---------------------------- | ---------- |
| \kamotish{\lou\3\hou2\i}     | 他们       |
| \kamotish{\lou\3\sou\hou2\i} | 她们       |
| \kamotish{\lou\3其}          | 它们; 他们 |

**1.** \kamotish{\hou2\i\wou\3\mi\e\3友\mou\2}  
　　发音: *hou i wǒu mi ě yǒu móu*  
　　译文: 他是我的朋友。

**2.** \kamotish{\sou\hou2\i\wou\3\hou2\i\e\3母\mou\2}  
　　发音: *sou hou i wǒu hou i ě mǔ móu*  
　　译文: 她是他的妈妈。

**3.** \kamotish{\lou\3其\wou\3\mi\e\3cait\mou\2}  
　　发音: *lǒu qí wǒu mi ě cait móu*  
　　译文: 它们是我的猫。

**指得更清楚: 近处、远处、有生命、无生命**

\kamotish{\ku\i} 什么都可以指。需要说得更清楚时, 可以换用下面四个词:

| 词                  | 发音  | 指什么       |
| ------------------- | ----- | ------------ |
| \kamotish{\kou\i\2} | kou í | 近处的人或物 |
| \kamotish{\bi\i\2}  | bi í  | 远处的人或物 |
| \kamotish{\a\i\2}   | a í   | 有生命的东西 |
| \kamotish{\sou\i\2} | sou í | 无生命的东西 |

它们都是代词, 和 \kamotish{\ku\i} 一样, 可以放在名词的位置。近远和有无生命是**两种不同的区分**: 近处的猫既可以用 \kamotish{\kou\i\2}, 也可以用 \kamotish{\a\i\2}; 远处的书既可以用 \kamotish{\bi\i\2}, 也可以用 \kamotish{\sou\i\2}。

复数一律在前面加 \kamotish{\lou\3}: \kamotish{\lou\3\kou\i\2} (这些)、\kamotish{\lou\3\bi\i\2} (那些)、\kamotish{\lou\3\a\i\2}、\kamotish{\lou\3\sou\i\2}。

| 曹语                                     | 意思                         |
| ---------------------------------------- | ---------------------------- |
| \kamotish{\kou\i\2\wou\3\mi\e\3書\mou\2} | 这是我的书。                 |
| \kamotish{\bi\i\2\wou\3\yu\e\3友\mou\2}  | 远处那位是你的朋友。         |
| \kamotish{\a\i\2\wou\3\mi\e\3cait\mou\2} | 它是我的猫。(指有生命的东西) |

### 5. 结构的嵌套

本课和第 1 课的结构:

| 结构                     | 空位放什么                 | 整体是什么 |
| ------------------------ | -------------------------- | ---------- |
| A\kamotish{\wou\3}B      | A、B: 除句子外几乎任何东西 | 句子       |
| A\kamotish{\ka\3\mou2\2} | A: 人名                    | 名词       |
| A\kamotish{\xi\2}        | A: 动词                    | 名词       |
| \kamotish{\lou\3}A       | A: 名词                    | 名词       |
| A\kamotish{\e\3}B        | A、B: 名词                 | 名词       |

注意后四个结构: 它们的空位都接受名词, **它们本身也是名词**。所以它们可以互相放进对方的空位, 也可以放进自己的空位, 一层套一层。这叫做**嵌套**。

**例 1**: \kamotish{\lou\3\mi\e\3cait\wou\3kiut\mou\2} (我们的猫很可爱)

| 层次 | 结构                                            | 结果                                                  |
| ---- | ----------------------------------------------- | ----------------------------------------------------- |
| ①    | \kamotish{\lou\3}A, A = \kamotish{\mi}          | \kamotish{\lou\3\mi} 我们                             |
| ②    | A\kamotish{\e\3}B, A = ①, B = \kamotish{cait}   | \kamotish{\lou\3\mi\e\3cait} 我们的猫                 |
| ③    | A\kamotish{\wou\3}B, A = ②, B = \kamotish{kiut} | \kamotish{\lou\3\mi\e\3cait\wou\3kiut} 我们的猫很可爱 |

**例 2**: A\kamotish{\e\3}B 可以一直套下去

| 曹语                             | 意思             |
| -------------------------------- | ---------------- |
| \kamotish{\mi\e\3友}             | 我的朋友         |
| \kamotish{\mi\e\3友\e\3父}       | 我朋友的父亲     |
| \kamotish{\mi\e\3友\e\3父\e\3車} | 我朋友的父亲的车 |

读的时候**从左往右**: ((我的朋友) 的父亲) 的车。

**例 3**: 更多嵌套

**1.** \kamotish{\tou\ou\mou\ka\3\mou2\2\e\3母\wou\3\mi\e\3授\xi\2\mou\2}  
　　发音: *tou ou mou kǎ móu ě mǔ wǒu mi ě shòu xí móu*  
　　译文: Tom 先生的妈妈是我的老师。

**2.** \kamotish{\mi\e\3友\e\3父\wou\3\lou\3\yu\e\3领导\xi\2\pou\2\chi\4}  
　　发音: *mi ě yǒu ě fù wǒu lǒu yu ě lǐng dǎo xí póu chì*  
　　译文: 我朋友的父亲是你们的领导。

**3.** \kamotish{\lou\3学\xi\2\e\3授\xi\2\wou\3\e\a\ou\2\ka\3\mou2\2\mou\2}  
　　发音: *lǒu xué xí ě shòu xí wǒu e a óu kǎ móu móu*  
　　译文: 学生们的老师是曹先生。

**代入的观念是学习曹语的基础。** 遇到复杂的句子, 先找到 \kamotish{\wou\3}, 把句子分成 A 和 B 两半, 再分别拆开 A 和 B。

### 6. 数字与序数词

数字和名词之间也可以用 \kamotish{\e\3}: \kamotish{2\e\3書} (两本书)。如果要说"第几个", 就在普通数字之后加上 \kamotish{sis}, 再接 \kamotish{\e\3} 和名词:

| 数量                      | 顺序                           |
| ------------------------- | ------------------------------ |
| \kamotish{2\e\3楼} 两层楼 | \kamotish{2sis\e\3楼} 第二层   |
| \kamotish{3\e\3書} 三本书 | \kamotish{3sis\e\3書} 第三本书 |

\kamotish{sis} 不改变数字的大小, 只把"多少"变成"第几"。\kamotish{2sis\e\3楼} 整体仍是名词, 可以放进前面学过的结构。

## 四、应用课文

### 应用课文一: 介绍朋友

王向 Kim 介绍 Teo。

**王**: \kamotish{\kou\i\mou,\hou2\i\wou\3\mi\e\3友。\hou2\i\e\3名\wou\3\tou\yu\ou\mou\2。}  
　　*kou i mou, hou i wǒu mi ě yǒu. hou i ě míng wǒu tou yu ou móu.*  
　　(Kim, 他是我的朋友。他的名字是 Teo。)

**Kim**: \kamotish{\kou\hou2\mou\2!\yu\wou\3NUS学院\e\3学\xi\2\shi\2?}  
　　*kou hou móu! yu wǒu NUS xué yuàn ě xué xí shí?*  
　　(你好! 你是新加坡国立大学的学生吗?)

**Teo**: \kamotish{\lou\3\lou\3。\yu\i…}  
　　*lǒu lǒu. yu i*  
　　(是的。你也……)

**Kim**: \kamotish{\mi\wou\3北京学院\e\3学\xi\2\mou\2。}  
　　*mi wǒu běi jīng xué yuàn ě xué xí móu.*  
　　(我是北京大学的学生。)

### 应用课文二: 照片

李给 Sakura 看手机里的照片。

**Sakura**: \kamotish{\sou\hou2\i\wou\3\yu\e\3母\shi\2?}  
　　*sou hou i wǒu yu ě mǔ shí?*  
　　(她是你的妈妈吗?)

**李**: \kamotish{\lou\3\lou\3。\mi\e\3母\wou\3授\xi\2\mou\2。}  
　　*lǒu lǒu. mi ě mǔ wǒu shòu xí móu.*  
　　(是的。我的妈妈是老师。)

**Sakura**: \kamotish{\hou2\i\wou\3\yu\e\3父\shi\2?}  
　　*hou i wǒu yu ě fù shí?*  
　　(他是你的爸爸吗?)

**李**: \kamotish{\bou\3\bou\3。\hou2\i\wou\3\mi\e\3母\e\3友\mou\2。}  
　　*bǒu bǒu. hou i wǒu mi ě mǔ ě yǒu móu.*  
　　(不是。他是我妈妈的朋友。)

**Sakura**: \kamotish{\a\i\2\wou\3\yu\e\3cait\shi\2?}  
　　*a í wǒu yu ě cait shí?*  
　　(它是你的猫吗?)

**李**: \kamotish{\lou\3\lou\3!\lou\3\mi\e\3cait\wou\3kiut\mou\2!}  
　　*lǒu lǒu! lǒu mi ě cait wǒu kiut móu!*  
　　(是的! 我们的猫很可爱!)

## 五、说明

1. **称呼朋友时可以不加 \kamotish{\ka\3\mou2\2}**: 王直接叫 \kamotish{\kou\i\mou}, 因为他们是朋友。王一口气说了两句话, 只在第二句末尾加 \kamotish{\mou\2}。
2. **Teo 的话没说完**: 他想说"你也是这里的学生吗?", 但还没说完, Kim 就回答了。"也"的说法在第 3 课学习。
3. **\kamotish{\mi\e\3母\e\3友}**: "我妈妈的朋友", 两层 A\kamotish{\e\3}B 嵌套。
4. **\kamotish{\lou\3\mi\e\3cait}**: "我们的猫", 说明猫是全家的。如果说 \kamotish{\mi\e\3\lou\3cait}, 就是"我的猫们"。

## 三、语法详解

### 1. 和 \kamotish{\wou\3} 用法相同的三个词

第 1 课学过 A\kamotish{\wou\3}B (A 是 B)。有三个词可以替换 \kamotish{\wou\3}, 用法完全一样, 只是意思不同:

| 句型                | 意思     |
| ------------------- | -------- |
| A\kamotish{\wou\3}B | A 是 B   |
| A\kamotish{\sou\3}B | A 有 B   |
| A\kamotish{\i\3}B   | A 也是 B |
| A\kamotish{\zhi\3}B | A 在 B   |

"用法完全一样"是指:

- A 和 B 能放的东西相同;
- 语气词的用法相同;
- 疑问、否定的方法也相同。

### 2. A\kamotish{\sou\3}B: A 有 B

**1.** \kamotish{\mi\sou\3cait\mou\2}  
　　发音: *mi sǒu cait móu*  
　　译文: 我有猫。

**2.** \kamotish{\tou\ou\mou\sou\3車\mou\2}  
　　发音: *tou ou mou sǒu chē móu*  
　　译文: Tom 有车。

**3.** \kamotish{\mi\e\3母\sou\3hous\pou\2\chi\4}  
　　发音: *mi ě mǔ sǒu hous póu chì*  
　　译文: 我的妈妈有房子。

**4.** \kamotish{\yu\sou\3友\shi\2?}  
　　发音: *yu sǒu yǒu shí?*  
　　译文: 你有朋友吗?

**5.** \kamotish{\lou\3\lou\3。\mi\sou\3友\mou\2。}  
　　发音: *lǒu lǒu. mi sǒu yǒu móu.*  
　　译文: 有。我有朋友。

**否定**: 和 \kamotish{\wou\3} 一样, 把句末的语气词换成否定语气词:

**6.** \kamotish{\mi\sou\3cait\bou\3\mou\2}  
　　发音: *mi sǒu cait bǒu móu*  
　　译文: 我没有猫。

**7.** \kamotish{\mi\sou\3車\pou\2\chi\4\wu\2\le\4}  
　　发音: *mi sǒu chē póu chì wú lè*  
　　译文: 我没有车。(正式)

### 3. A\kamotish{\i\3}B: A 也是 B

**1.** \kamotish{\yu\wou\3学\xi\2,\mi\i\3学\xi\2\mou\2}  
　　发音: *yu wǒu xué xí, mi ǐ xué xí móu*  
　　译文: 你是学生, 我也是学生。

**2.** \kamotish{\hou2\i\wou\3中国人,\sou\hou2\i\i\3中国人\mou\2}  
　　发音: *hou i wǒu zhōng guó rén, sou hou i ǐ zhōng guó rén móu*  
　　译文: 他是中国人, 她也是中国人。

**3.** \kamotish{\tou\yu\ou\wou\3喜,\kou\i\mou\i\3喜\mou\2}  
　　发音: *tou yu ou wǒu xǐ, kou i mou ǐ xǐ móu*  
　　译文: Teo 很开心, Kim 也很开心。

\kamotish{\i\3} 本身已经包含了"是"的意思, 所以**不要**再加 \kamotish{\wou\3}:

- ✓ \kamotish{\mi\i\3学\xi\2}
- ✗ \kamotish{\mi\i\3\wou\3学\xi\2}

**否定**: \kamotish{\mi\i\3学\xi\2\bou\3\mou\2} (我也不是学生)。

### 4. A\kamotish{\zhi\3}B: A 在 B

B 是一个地点:

**1.** \kamotish{\mi\zhi\3sin-gia-pu-la\mou\2}  
　　发音: *mi zhǐ sin gia pu la móu*  
　　译文: 我在新加坡。

**2.** \kamotish{\mi\e\3cait\zhi\3\mi\e\3舍\mou\2}  
　　发音: *mi ě cait zhǐ mi ě shě móu*  
　　译文: 我的猫在我的宿舍。

**3.** \kamotish{\e\a\ou\2\ka\3\mou2\2\zhi\3北京\pou\2\chi\4}  
　　发音: *e a óu kǎ móu zhǐ běi jīng póu chì*  
　　译文: 曹先生在北京。

**4.** \kamotish{\yu\e\3犬\zhi\3\yu\e\3hous\shi\2?}  
　　发音: *yu ě quǎn zhǐ yu ě hous shí?*  
　　译文: 你的狗在你的房子里吗?

地点也可以是带有序数的名词: \kamotish{\mi\e\3舍\zhi\3-2sis\e\3楼\mou\2} (我的宿舍在第二层)。注意 \kamotish{2sis} 是"第二", \kamotish{2} 是"二"。

### 5. 否定的另一种方法: \kamotish{\bou\3} 放在前面

除了换语气词以外, 非正式的否定还有一种方法: 把 \kamotish{\bou\3} 放在 \kamotish{\wou\3} (或 \kamotish{\sou\3}、\kamotish{\i\3}、\kamotish{\zhi\3}) 的**前面**。

| 方法一: 换语气词                         | 方法二: \kamotish{\bou\3} 放在前面       | 意思         |
| ---------------------------------------- | ---------------------------------------- | ------------ |
| \kamotish{\yu\wou\3AI\bou\3\mou\2}       | \kamotish{\yu\bou\3\wou\3AI\mou\2}       | 你不是 AI。  |
| \kamotish{\mi\sou\3cait\bou\3\mou\2}     | \kamotish{\mi\bou\3\sou\3cait\mou\2}     | 我没有猫。   |
| \kamotish{\hou2\i\zhi\3北京\bou\3\mou\2} | \kamotish{\hou2\i\bou\3\zhi\3北京\mou\2} | 他不在北京。 |

注意:

1. 方法二末尾用的是肯定的 \kamotish{\mou\2}, 因为否定已经由前面的 \kamotish{\bou\3} 表达了。
2. **两种方法不要同时用**。\kamotish{\yu\bou\3\wou\3AI\bou\3\mou\2} 在语法上可以, 但听起来很奇怪。
3. 正式的否定**只有一种方法**: 句末的 \kamotish{\pou\2\chi\4\wu\2\le\4}。

### 6. A\kamotish{\wu}B: 头衔与身份

**(1) 正式的称呼**

A 是一个人 (或者被当作人来看待的事物), B 是他的地位、头衔或身份。A\kamotish{\wu}B 是正式场合称呼一个人的方式, 这时**不用** \kamotish{\ka\3\mou2\2}。

| 曹语                                 | 意思            |
| ------------------------------------ | --------------- |
| \kamotish{\e\a\ou\2\wu-pu-ro-fe-sor} | 曹教授          |
| \kamotish{王\wu-pu-ri-zen-te}        | 王主席          |
| \kamotish{李\wu-dok-tor}             | 李医生 / 李博士 |
| \kamotish{\e\a\ou\2\wu授\xi\2}       | 曹老师          |

比较:

| 称呼                                        | 场合                 |
| ------------------------------------------- | -------------------- |
| \kamotish{\e\a\ou\2\ka\3\mou2\2} 曹先生     | 礼貌、亲切, 日常使用 |
| \kamotish{\e\a\ou\2\wu-pu-ro-fe-sor} 曹教授 | 正式, 强调身份       |

A\kamotish{\wu}B 整体是一个名词, 可以放进任何句型:

**1.** \kamotish{\e\a\ou\2\wu-pu-ro-fe-sor\wou\3中国人\pou\2\chi\4}  
　　发音: *e a óu wu pu ro fe sor wǒu zhōng guó rén póu chì*  
　　译文: 曹教授是中国人。

**2.** \kamotish{\mi\e\3母\wou\3李\wu-dok-tor\pou\2\chi\4}  
　　发音: *mi ě mǔ wǒu lǐ wu dok tor póu chì*  
　　译文: 我的妈妈就是李医生。

**(2) 同位语**

B 不仅可以是一个头衔, 还可以是一个较长的名词短语, 说明 A 是什么人。这时 A\kamotish{\wu}B 很像中文的同位语"A, 这位 B"、"B A":

**3.** \kamotish{\e\a\ou\2\wu\e\a\ou\2\e\3言\e\3授\xi\2\zhi\3sin-gia-pu-la\pou\2\chi\4}  
　　发音: *e a óu wu e a óu ě yán ě shòu xí zhǐ sin gia pu la póu chì*  
　　译文: 曹语的老师曹先生在新加坡。

这里 B = \kamotish{\e\a\ou\2\e\3言\e\3授\xi\2} (曹语的老师)。同位语的 B 最常见的形式是"动词短语 + \kamotish{\xi\2}", 例如"民主的守护者", 这要等学了动词短语 (第 5 课) 和同位语从句 (第 13 课) 再详细讲。

**(3) 两种方向**

A\kamotish{\wu}B 有两种方向, 都是正确的:

| 方向                     | 例                                   | 意思                  |
| ------------------------ | ------------------------------------ | --------------------- |
| 专名 \kamotish{\wu} 身份 | \kamotish{\e\a\ou\2\wu-pu-ro-fe-sor} | 曹教授 (曹, 这位教授) |
| 类名 \kamotish{\wu} 专名 | \kamotish{市\wu北京}                 | 北京这座城市          |

**4.** \kamotish{市\wu北京\wou\3kol\pou\2\chi\4}  
　　发音: *shì wu běi jīng wǒu kol póu chì*  
　　译文: 北京这座城市很冷。

**5.** \kamotish{\e\a\ou\2\wu-pu-ro-fe-sor\zhi\3市\wu北京\pou\2\chi\4}  
　　发音: *e a óu wu pu ro fe sor zhǐ shì wu běi jīng póu chì*  
　　译文: 曹教授在北京这座城市。

后一种方向以后还会常见, 比如第 18 课的 \kamotish{名\wu丝路} ("丝路"这个名字)。

**注意**: \kamotish{\wu} 是一声。它和第 1 课正式否定语气词里的 \kamotish{\wu\2} 声调不同。

### 7. 感叹语气: \kamotish{\zhi\4}

把句末的 \kamotish{\mou\2} 换成 \kamotish{\zhi\4}, 句子就带上了感叹的语气:

| 陈述                                                  | 感叹                                                  |
| ----------------------------------------------------- | ----------------------------------------------------- |
| \kamotish{\yu\e\3cait\wou\3kiut\mou\2} 你的猫很可爱。 | \kamotish{\yu\e\3cait\wou\3kiut\zhi\4!} 你的猫真可爱! |
| \kamotish{\yu\wou\3si-mat\mou\2} 你很聪明。           | \kamotish{\yu\wou\3si-mat\zhi\4!} 你真聪明!           |
| \kamotish{\hou2\i\sou\3車\mou\2} 他有车。             | \kamotish{\hou2\i\sou\3車\zhi\4!} 他居然有车!         |

\kamotish{\zhi\4} 在一般文体和正式文体中都可以使用。正式文体中, 同样是把句末的 \kamotish{\pou\2\chi\4} 换成 \kamotish{\zhi\4}:

| 正式陈述                                                                    | 正式感叹                                                              |
| --------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| \kamotish{\e\a\ou\2\wu-pu-ro-fe-sor\wou\3si-mat\pou\2\chi\4} 曹教授很聪明。 | \kamotish{\e\a\ou\2\wu-pu-ro-fe-sor\wou\3si-mat\zhi\4!} 曹教授真聪明! |

### 8. 反问语气

**(1) 意思**

反问句的形式是疑问句, 但说话人其实**很肯定**, 用来强调、表示惊讶或不满。中文常说"难道……不……吗?"

**(2) 写法**

**肯定的句子** + 反问语气词:

|        | 反问语气词                                  |
| ------ | ------------------------------------------- |
| 非正式 | \kamotish{\bou\3\shi\2}                     |
| 正式   | \kamotish{\pou\2\chi\4\wu\3\le\4\a\4\shi\2} |

**1.** \kamotish{\yu\wou\3学\xi\2\bou\3\shi\2?}  
　　发音: *yu wǒu xué xí bǒu shí?*  
　　译文: 你难道不是学生吗? (你明明是学生!)

**2.** \kamotish{\hou2\i\wou\3\yu\e\3友\bou\3\shi\2?}  
　　发音: *hou i wǒu yu ě yǒu bǒu shí?*  
　　译文: 他难道不是你的朋友吗?

**3.** \kamotish{\yu\sou\3cait\bou\3\shi\2?}  
　　发音: *yu sǒu cait bǒu shí?*  
　　译文: 你不是有猫吗?

**4.** \kamotish{\e\a\ou\2\wu-pu-ro-fe-sor\zhi\3北京\pou\2\chi\4\wu\3\le\4\a\4\shi\2?}  
　　发音: *e a óu wu pu ro fe sor zhǐ běi jīng póu chì wǔ lè à shí?*  
　　译文: 曹教授难道不是在北京吗? (正式)

**(3) 容易混淆的语气词**

| 语气词                                      | 意思     | 例                                                         |
| ------------------------------------------- | -------- | ---------------------------------------------------------- |
| \kamotish{\bou\3\mou\2}                     | 否定     | \kamotish{\yu\wou\3学\xi\2\bou\3\mou\2} 你不是学生。       |
| \kamotish{\bou\3\shi\2}                     | 反问     | \kamotish{\yu\wou\3学\xi\2\bou\3\shi\2?} 你难道不是学生吗? |
| \kamotish{\bou\3\bou\3}                     | 应答"不" | \kamotish{\bou\3\bou\3。} 不。                             |
| \kamotish{\pou\2\chi\4\wu\2\le\4}           | 正式否定 |                                                            |
| \kamotish{\pou\2\chi\4\wu\3\le\4\a\4\shi\2} | 正式反问 | 注意 \kamotish{\wu\3}、\kamotish{\a\4} 的声调              |

## 四、应用课文

### 应用课文一: 你有猫吗?

Kim 在 Tom 的宿舍门口听到猫叫。

**Kim**: \kamotish{\tou\ou\mou,\yu\sou\3cait\shi\2?}  
　　*tou ou mou, yu sǒu cait shí?*  
　　(Tom, 你有猫吗?)

**Tom**: \kamotish{\lou\3\lou\3。\mi\e\3cait\zhi\3\mi\e\3舍\mou\2。}  
　　*lǒu lǒu. mi ě cait zhǐ mi ě shě móu.*  
　　(有。我的猫在我的宿舍里。)

**Kim**: \kamotish{\yu\e\3cait\wou\3kiut\zhi\4!}  
　　*yu ě cait wǒu kiut zhì!*  
　　(你的猫真可爱!)

**Tom**: \kamotish{\yu\sou\3cait\shi\2?}  
　　*yu sǒu cait shí?*  
　　(你有猫吗?)

**Kim**: \kamotish{\bou\3\bou\3。\mi\sou\3犬\mou\2。}  
　　*bǒu bǒu. mi sǒu quǎn móu.*  
　　(没有。我有狗。)

**Tom**: \kamotish{\yu\e\3犬\zhi\3\yu\e\3舍\shi\2?}  
　　*yu ě quǎn zhǐ yu ě shě shí?*  
　　(你的狗在你的宿舍吗?)

**Kim**: \kamotish{\bou\3\bou\3。其\zhi\3han-guk\mou\2。}  
　　*bǒu bǒu. qí zhǐ han guk móu.*  
　　(不在。它在韩国。)

### 应用课文二: 曹教授

王和李在谈论老师。

**王**: \kamotish{\e\a\ou\2\wu-pu-ro-fe-sor\zhi\3北京\shi\2?}  
　　*e a óu wu pu ro fe sor zhǐ běi jīng shí?*  
　　(曹教授在北京吗?)

**李**: \kamotish{\bou\3\bou\3。\hou2\i\zhi\3sin-gia-pu-la\mou\2。}  
　　*bǒu bǒu. hou i zhǐ sin gia pu la móu.*  
　　(不在。他在新加坡。)

**王**: \kamotish{\hou2\i\wou\3NUS学院\e\3授\xi\2\shi\2?}  
　　*hou i wǒu NUS xué yuàn ě shòu xí shí?*  
　　(他是新加坡国立大学的老师吗?)

**李**: \kamotish{\hou2\i\wou\3\lou\3\mi\e\3授\xi\2\bou\3\shi\2?}  
　　*hou i wǒu lǒu mi ě shòu xí bǒu shí?*  
　　(他难道不是我们的老师吗?)

**王**: \kamotish{\lou\3\lou\3……}  
　　*lǒu lǒu*  
　　(对哦……)

## 五、说明

1. **\kamotish{\bou\3\bou\3} 也可以回答"有吗""在吗"**: Kim 和李都用 \kamotish{\bou\3\bou\3} 回答了"你有猫吗""他在北京吗", 译成"没有""不在"。
2. **李的反问**: \kamotish{\hou2\i\wou\3\lou\3\mi\e\3授\xi\2\bou\3\shi\2?} 表示"他当然是我们的老师, 你怎么会不知道?"。
3. **\kamotish{其}** 在 Kim 的最后一句话中指她的狗。
