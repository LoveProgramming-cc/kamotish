卡谋语在线工具

在线写卡谋语，或把含 \kamotish{…} 和数学公式的 Markdown 导出成 PDF。所有处理都在你的浏览器里完成，文件不会上传。

拼读直接写小写字母，音节之间用 -；字素写 \名字；音调写 \2 \3 \4；汉字和标点原样保留。完整写法见使用手册。

把 .md 文件拖到这里

    在打印窗口里选"存为 PDF"。想要页码：在打印设置里勾选"页眉和页脚"。
    文件里用相对路径引用的图片在网页版中无法显示；需要图片请用本地版 (见"下载与说明")。

    左边加入 Markdown 文件后，这里显示预览。

    下载

    • kamotish-chrome.zip：浏览器插件 (Chrome / Edge)，网页里的 \kamotish{…} 自动渲染
    • kamotish-firefox.zip：同上，Firefox 版
    • kamotish.js：渲染库，可以放进自己的网页
    • markdown-it-kamotish.js：markdown-it 插件
