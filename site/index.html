    卡谋语写 \kamotish{…}；数学公式写 $…$、$$…$$ 或 ```latex 代码块。

    拼读直接写小写字母，音节之间用 -；字素写 \名字（如 \nou）；音调写 \2 \3 \4；汉字和标点原样保留。完整写法见使用手册。

    两个版本

    本工具有在线版和本地版，是同一个页面：

    • 在线版：打开网页即可用。导出 PDF 用浏览器的打印功能 (选“存为 PDF”，自定义页码建议使用新版 Chrome / Edge，并关闭打印设置中的“页眉和页脚”，避免重复)。 选择或拖入整个文件夹可显示相对路径图片。单独选择 Markdown 文件无法读取旁边的图片。 在 Chrome / Edge 里，修改过的文件可以直接保存回原文件；其他浏览器会下载修改后的文件。
    • 本地版：在电脑上运行 tools/md2pdf，额外支持：按路径载入整个文件夹、 一键批量导出 PDF (自动页码)、PDF 直接存进指定文件夹、不联网也能用。

    下载

    • kamotish-chrome.zip：浏览器插件 (Chrome / Edge)，网页里的 \kamotish{…} 自动渲染
    • kamotish-firefox.zip：同上，Firefox 版
    • kamotish.js：渲染库，可以放进自己的网页
    • markdown-it-kamotish.js：markdown-it 插件
