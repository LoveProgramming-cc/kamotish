# Kamotish Writer 3 — 卡谋语长篇文稿编辑器

[中文](#部署到-github-pages) · 完全静态网页 · SVG 字素 / 拟素渲染 · 原生 `.kamodoc` 文稿 · Rime Ice 开源词库

## 本次更新 (3.0)：参照 Google Docs 重构

编辑器核心从浏览器原生 `contenteditable` + `execCommand` 换成基于文档模型的 [ProseMirror](https://prosemirror.net)（MIT）。所有修改都是可撤销的事务，不再依赖浏览器各自的编辑行为。旧版的 `.kamodoc`、自动保存的文稿库和 Markdown 都能直接打开。

- **卡谋语字素是原子节点。** 一个字素或拟素音节就是一个字符：方向键逐个跨过，Backspace / Delete 整个删除，Home / End、⌘← / ⌘→ 能越过字素到行首行尾，不再出现多余换行或光标消失。
- **撤销 / 重做覆盖一切操作**，包括字号、颜色、声调、表格和图片。每个工具栏操作是独立的一步。
- **菜单栏**：文件、编辑、插入、格式、工具，鼠标悬停可在已打开的菜单间切换，菜单项旁显示快捷键。
- **工具栏**：查找、撤销重做、缩放、段落样式、字体、字号（− / 输入 / +）、加粗斜体下划线删除线、文字颜色与突出显示颜色（60 色调色板 + 自定义）、链接、图片、卡谋语、四种对齐、行距、项目符号 / 编号列表、缩进、清除格式。按钮状态跟随光标。
- **快捷键**与 Google Docs 一致：⌘B / I / U、⌘⇧X 删除线、⌘. / ⌘, 上下标、⌘K 链接、⌘⌥0–3 正文 / 标题、⌘⇧7 / 8 列表、⌘⇧L / E / R / J 对齐、⌘[ / ⌘] 缩进、⌘⇧. / ⌘⇧, 字号、⌘\ 清除格式、⌘F 查找、⌘⇧H 替换、⌘⇧C 字数统计、⌘/ 快捷键列表。Windows 用 Ctrl。
- **自动识别 Markdown**：行首输入 `# ` 变标题、`- ` 变列表、`1. ` 变编号、`> ` 变引用、`---` 变水平线；Backspace 可撤回自动格式。
- **列表**：Enter 新建项，空项按 Enter 退出列表，Tab / ⇧Tab 调整层级。
- **查找和替换**：高亮全部匹配、上一个 / 下一个、区分大小写、替换、全部替换。
- **链接**：⌘K 插入或编辑；光标在链接内时显示链接气泡（打开、编辑、移除）。
- **表格**：插入时可在格子上选行列数；单元格可多选；右键菜单插入 / 删除行列、合并 / 拆分单元格、切换表头、删除表格；拖动列边线调整列宽；Tab 跳到下一格。
- **图片**：插入、粘贴截图或直接拖入；选中后拖动右下角调整大小。
- **文稿大纲**跟随光标高亮当前章节；状态栏字数可点开字数统计（含选中部分）。
- **LaTeX 公式**：用工具栏 ∑ 或“插入 → 公式 / 公式块”插入；正文里输入的 `$` 始终是普通字符，不会自动变成公式。插入第一个公式后，工具栏下方出现**公式工具栏**（同 Google Docs）：“新建公式”和希腊字母、运算符、关系、数学结构、箭头五组符号，编辑公式时点符号直接插入，否则新建一个公式；可用 × 隐藏，“工具 → 显示公式工具栏”再打开。单击公式即可编辑：源码框带模板与常用符号，下方实时预览；Enter 完成，⇧Enter 换行，Esc 取消。导入 Markdown 时 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 和 ```` ```latex ```` 代码块都还原成可编辑公式，导出时写回 `$…$` / `$$…$$`，正文里的 `$` 自动转义。
- **右键菜单**：正文任意位置右键显示编辑器菜单（剪切、复制、粘贴、粘贴为纯文本、删除、链接、插入公式、清除格式、全选）；在字素上可改声调，在公式上可编辑，在表格里可增删行列、合并单元格。按住 ⇧ 右键仍是浏览器菜单。浏览器第一次从菜单粘贴时会请求剪贴板权限。
- **卡谋语输入**：输入法保持原有操作；候选分多行时 ↓ / ↑ 先在行间移动，到最后一行再翻页；选中一个字素（单击或方向键）后直接按 1–4 改声调。连续输入的字素合并为一个 `\kamotish{...}`。复制时纯文本为 `\kamotish{...}` 源码，粘贴含 `\kamotish{...}` 的文本会还原为字素。

### 输入法示例

输入 `nou` 后，按 `1` / `2` / `3` / `4` 分别提交一至四声字素。左右箭头选择候选，上下箭头翻页，空格或 Enter 提交当前候选；也可点击候选。选择拟素候选后，数字键设置该拟素声调。未组合拼音时，方向键照常移动正文光标。

### 保存格式的分工

| 文件 | 用途 | 保真范围 |
| --- | --- | --- |
| `.kamodoc` | **主文稿 / 正式备份** | 完整保存编辑器支持的段落、行内格式和字素/音节源码, 可往返编辑 |
| `.md` | 分享、转移到现有 `\kamotish{...}` Markdown 流程 | 导出支持的 Markdown 及部分内嵌 HTML 样式; **复杂富文本导入不保证无损** |
| `.pdf` | 排版完成后阅读、打印 | SVG 采用矢量绘制; PDF 内容不提供编辑器内部源代码 |

「无损」是指 **Kamotish Writer 2 支持的节点和样式** 在 `.kamodoc` 的导出 / 导入往返间保持一致, 不是指任意 Word、Google Docs 或外部 HTML 的完整兼容。`.kamodoc` 是公开结构的 JSON, 可自行分析与批量处理。

## 已合并到 Kamotish 主项目

编辑器位于主仓库的 `writer/`，主项目的 Pages 工作流统一部署页面并构建雾凇词库。编辑器直接挂载在主站“文稿编辑”页签中，与文档 → PDF 共用导航和文稿；旧 `writer/` 地址会跳转到主站。渲染库统一使用 `web/kamotish.js`，不再维护旧版副本。旧文稿中的字素 `\no` 在载入时迁移为 `\nou`，普通拼读音节 `no` 保持原义。

### Markdown 与插图

“文件 → 导入单个文件”可直接导入之前的 `\kamotish{…}` Markdown。标题、引用、列表、链接、表格、代码与图片按 Markdown 解析，不再逐段用正则替换。带本地图片时点击“文件 → 导入文件夹”，选择同时包含 `.md` 和图片的文件夹，再选择文稿；主站文档预览也可通过“编辑文稿”在同页带入当前文稿与图片。编辑后切回文档 → PDF，源码与图片会同步回文档工具。

图片嵌入 `.kamodoc` 中，可离线往返编辑。导出 Markdown 保留图片原相对路径，分享时需带上图片目录。复杂富文本的 MD 往返仍不保证无损，正式备份建议使用 `.kamodoc`。

### 本地运行

在主仓库根目录执行：

```bash
npm ci --prefix tools/md2pdf
node tools/md2pdf/server.js
# 访问 http://127.0.0.1:4747/#writer
```

输入法的常用字、词语和词频来自雾凇拼音词库。在线版由 Pages 工作流自动构建；本地版第一次双击 `启动.command` 时会自动下载编译（约 30 MB，需联网），也可手动运行 `python3 writer/scripts/build_rime_ice.py --output-dir writer/data`。没有这个词库时，输入法只能用 xpinyin 基础字表，候选按编码排序，常用字会排在后面。生成的词库不提交到仓库（GPL-3.0，见 `.gitignore`）。

### 回归测试

```bash
node writer/tests/test_ime.cjs
python3 -m unittest discover -s writer/tests -p 'test_dictionary.py'
# 有 Chromium、Playwright 和 PyMuPDF 时:
```

浏览器测试使用脚本注入, 避免受受限测试环境对 localhost / file URL 的屏蔽, 不会修改实际网站代码。

### 仍待完善的能力

- 没有分页视图：正文是一张连续的 A4 宽纸，分页在“排版 / PDF”时由浏览器完成。
- 没有批注、修订模式和多人协作；文档只保存在本浏览器，请定期下载 `.kamodoc` 备份。
- SVG 单位可以逐字素或拟素**音节**选中，不能在单个拟素音节的内部再选择其中的拉丁字符。
- Rime Ice 提供开源汉字表和带词频词库；这是自定义 JS 拼音拼接方案，**不是**完整 librime 引擎。

### 重新打包 ProseMirror

`writer/vendor/prosemirror.js` 是打包好的文件，部署时不需要构建。升级版本时：

```bash
npm install --prefix tools/md2pdf
node tools/md2pdf/build-writer-vendor.mjs
```

## 文稿管理与插入

“我的文稿”管理保存在此浏览器中的多份文稿。可新建、搜索、排序、打开、重命名、创建副本及删除。返回列表会保存并关闭当前文稿；页面刷新后先显示列表，不自动恢复上次打开的正文。旧版缓存只迁移一次，删除后的旧文稿不会再从旧缓存中恢复。

自动保存与 `⌘/Ctrl+S` 使用 IndexedDB，图片随文稿保存。保存失败时编辑器保留当前文稿，下载 `.kamodoc` 可备份。

“插入”菜单提供：本地图片（可多选）、表格（行列数与可选表头）、分隔线、卡谋语。内容在光标处插入，可继续编辑、保存并导出 PDF。新插入图片在 Markdown 导出中内嵌；导入时已有的相对路径图片保留原路径。
